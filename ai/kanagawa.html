灰墨 MoH_UIAI 组件指令 完整教程

神奈川（kanagawa） · 灰墨 MoH_UI

虚构日式茶器与艺术品牌「浪见屋 NAMAMIYA」整页。墨色底（#1F1F28）配靛蓝主色、朱赤克制点睛与衬线标题，Hero 为自绘线稿海浪，配三件器物卡、展讯卡、匠人工序与预约 CTA；挂 daisyUI [data-theme="kanagawa"] 即整站换肤，页面全部使用 daisyUI 组件拼装、零依赖。

来源：Kanagawa.nvim (rebelot/kanagawa.nvim)（MIT） · 上游色板

在线整页案例：https://noii-y.github.io/moh-ui/themes/kanagawa/demo.html

用法一：照着整页做一个同款（推荐，复现效果最接近）

下面是该主题完整、可直接运行的整页源码（零依赖，保存为 .html 双击即可看）。让 AI 先 1:1 还原结构与视觉，再替换成你的业务内容；页面顶部「复制 AI 指令」会把含本源码的完整指令复制成纯文本，不联网也能复现。

换成你自己的业务时必须守住的视觉特征

  • 墨色底为主：base-100 #1F1F28 / base-200 #223249（蓝灰浮起卡片）/ base-300 #16161D（最深），文字用 fujiWhite #DCD7BA；正文不要用靛蓝或朱赤，只用于标题强调与主操作。
  • 主色靛蓝 crystalBlue #7E9CD8 只给主按钮、选中态与链接；朱赤 peachRed #FF5D62 全篇只出现 1~2 次（如展讯日期或一句强调），绝不大面积铺红铺蓝。
  • 品牌名与各级标题用衬线（宋体系 / Georgia）并加 1~4px 字间距，正文用无衬线；标题克制、留白要足，版块之间用 currentColor 约 22% 透明度的发丝线分隔。
  • 所有器物与装饰图只用 currentColor 单色线稿 SVG：海浪要画出多层浪涛与浪尖飞沫（圆点），茶碗、铁壶、和纸三款器物轮廓差异要明显；不用彩色照片、不用 emoji、不用渐变。
  • 主按钮靛蓝底必须配近墨色文字（daisyUI 按 primary-content 自动取 #1F1F28），次要操作用幽灵按钮；按钮只写真实动作（预约看展、选购器物、查看器物），不写颜色名。
  • 文案讲真实动作与真实场景（看展、试茶、开窑），器款附「¥X 起」的虚构价格区间，展览写虚构展名/日期/场地并注明示例数据，不写「奢华传承」这类空话。
  • 390px 窄屏顶栏自然折行、卡片单列、横向发丝分隔线不溢出；手机上 Hero 海浪保持完整不裁切。

用法二：只给已有项目换肤

① 在 <head> 引入 daisyUI 5 底座：

<link rel="stylesheet" href="https://noii-y.github.io/moh-ui/vendor/daisyui.css">
<link rel="stylesheet" href="https://noii-y.github.io/moh-ui/themes/kanagawa/tokens.css">

② 在 <html> 挂 data-theme="kanagawa"，组件类名一行都不用改。上面的 tokens.css 覆盖 [data-theme="kanagawa"] 下的全部 --color-* 变量。

③ 本主题完整变量（要改颜色就覆盖这些变量，不要在组件里硬编码色值）：

/*! 灰墨 kanagawa · 神奈川 —— 墨彩 + 靛蓝 + 朱赤的日系主题
   覆盖 daisyUI 5 主题变量（MIT，daisyUI © Pouya Saadeghi）。
   色值逐字取自 rebelot/kanagawa.nvim 官方 wave 深色主题色板（MIT，© 2021 Tommaso Laurenzi），
   灵感来自葛饰北斋《神奈川冲浪里》。
   用法：项目已引入 daisyUI 后，<link> 本文件，并在 <html data-theme="kanagawa"> 即整站换肤。 */

[data-theme="kanagawa"] {
  color-scheme: dark;

  /* 底与纸：墨色三层 —— 默认底 sumiInk #1F1F28 / 卡片浮起 waveBlue1 #223249 / 最深浮窗 sumiInk0 #16161D */
  --color-base-100: #1F1F28;
  --color-base-200: #223249;
  --color-base-300: #16161D;
  --color-base-content: #DCD7BA; /* fujiWhite 默认前景 */

  /* 主色：靛蓝 crystalBlue #7E9CD8（函数 / 标题色），只留给主操作与选中态 */
  --color-primary: #7E9CD8;
  --color-primary-content: #1F1F28;

  /* 次色：紫 (oniViolet #957FB8)；强调色：朱赤 peachRed #FF5D62，克制点睛 */
  --color-secondary: #957FB8;
  --color-secondary-content: #1F1F28;
  --color-accent: #FF5D62;
  --color-accent-content: #1F1F28;

  /* 中性面：墨灰 #54546D，用于边框与分隔 */
  --color-neutral: #54546D;
  --color-neutral-content: #DCD7BA;

  /* 语义色：诊断与语法色直接映射 */
  --color-info: #7FB4CA;      /* springBlue */
  --color-info-content: #1F1F28;
  --color-success: #98BB6C;   /* springGreen */
  --color-success-content: #1F1F28;
  --color-warning: #FF9E3B;   /* roninYellow */
  --color-warning-content: #1F1F28;
  --color-error: #E82424;     /* samuraiRed */
  --color-error-content: #1F1F28;

  /* 圆角 / 尺寸 / 边框：克制小圆角，日式留白取向 */
  --radius-selector: 0.5rem;
  --radius-field: 0.375rem;
  --radius-box: 0.625rem;
  --size-selector: 0.25rem;
  --size-field: 0.25rem;
  --border: 1px;
  --depth: 1;
  --noise: 0;
}

④ 组件全部走 daisyUI 语义类（btn / card / table / input 等），不要硬编码颜色。
