粗野主义（mo-brutal） · 灰墨 MoH_UI

个性品牌落地页。3px 厚黑边、直角、零模糊硬阴影、海军蓝 + 撞色红，顶栏 + 超大 hero + 特性卡 + 三档价格 + 订阅 CTA；挂 data-theme="mo-brutal" 即整站换肤，页面全部使用 daisyUI 组件拼装、零依赖。

来源：灰墨二创主题（MIT）

在线整页案例：https://noii-y.github.io/moh-ui/themes/mo-brutal/demo.html

用法一：照着整页做一个同款（推荐，复现效果最接近）

下面是该主题完整、可直接运行的整页源码（零依赖，保存为 .html 双击即可看）。让 AI 先 1:1 还原结构与视觉，再替换成你的业务内容；页面顶部「复制 AI 指令」会把含本源码的完整指令复制成纯文本，不联网也能复现。

换成你自己的业务时必须守住的视觉特征

  • 三层浅色底：base-100 #f7f7f7 页面、base-200 #ffffff 卡片、base-300 #ececec 区块底；所有层次一律靠 3px 纯黑边框（--border:3px、--radius-selector/field/box 全为 0 直角）分隔，禁止圆角、禁止 1px 细描边。
  • 硬阴影是灵魂：卡片与主按钮用 box-shadow:6px 6px 0 #111，小元素用 4px 4px 0 #111，零模糊、零透明度；禁止模糊投影、渐变、玻璃拟态与发光。
  • 海军蓝主色 #1e3a8a 白字只给实心主按钮；撞色红 #dc2626 只用于 hero 小徽章、kicker 小标题（12px / 字距 2px）与「推荐」角标；纯黑 #111 本身就是角色（推荐套餐卡、页脚黑底白字），不要随手把黑当普通背景铺。
  • 字体一律特粗黑体：hero 标题 58px / font-weight 900 / 字距 -2px，区块标题 30px / 900，导航与正文也至少 600~700；不要细字、不要衬线。
  • hero 标题里的关键词用白色衬底块（background:#fff、内联 padding 0 8~10px）盖住粗体文字，像印章盖在招牌上。
  • 功能图标一律 stroke #111、stroke-width 2.5 的粗线条性 SVG，放进「46px、3px 黑边、base-300 底」的方块；价格清单对勾用 #16a34a / #34d399 的 3px 粗线，不用 emoji。
  • ≤860px 三栏网格塌为单列、hero 标题缩到 40px；≤560px 订阅输入框与按钮占满整行，整页不横向溢出。

③ 本主题完整变量（要改颜色就覆盖这些变量，不要在组件里硬编码色值）：

/*! 灰墨 mo-brutal · 粗野主义（浅色）—— 个性品牌落地页主题
   覆盖 daisyUI 5 主题变量（MIT，daisyUI © Pouya Saadeghi）。
   用法：项目已引入 daisyUI 后，<link> 本文件，并在 <html data-theme="mo-brutal"> 即整站换肤。
   气质：3px 厚黑边、直角、硬阴影（6px 偏移零模糊）、海军蓝与撞色红。
   灵感来源：neo-brutalism 界面风格（仅风格参考，非品牌素材）。 */

[data-theme="mo-brutal"] {
  color-scheme: light;

  /* 底与纸：浅灰底 + 纯白卡 + 浅灰层，靠厚黑边分隔层次 */
  --color-base-100: #f7f7f7;
  --color-base-200: #ffffff;
  --color-base-300: #ececec;
  --color-base-content: #111111;

  /* 主色：海军蓝（实心按钮与主操作） */
  --color-primary: #1e3a8a;
  --color-primary-content: #ffffff;

  /* 次色：黑块（粗野主义的黑） */
  --color-secondary: #111111;
  --color-secondary-content: #ffffff;

  /* 强调色：撞色红（徽章 / 提示等点缀） */
  --color-accent: #dc2626;
  --color-accent-content: #ffffff;

  --color-neutral: #111111;
  --color-neutral-content: #ffffff;

  /* 语义色 */
  --color-info: #1e40af;
  --color-info-content: #ffffff;
  --color-success: #16a34a;
  --color-success-content: #ffffff;
  --color-warning: #d97706;
  --color-warning-content: #ffffff;
  --color-error: #dc2626;
  --color-error-content: #ffffff;

  /* 圆角 / 边框：直角、3px 厚边，粗野主义取向 */
  --radius-selector: 0;
  --radius-field: 0;
  --radius-box: 0;
  --size-selector: 0.25rem;
  --size-field: 0.25rem;
  --border: 3px;
  --depth: 0;
  --noise: 0;
}

④ 组件全部走 daisyUI 语义类（btn / card / table / input 等），不要硬编码颜色。
