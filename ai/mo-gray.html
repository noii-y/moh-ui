灰墨 MoH_UIAI 组件指令 完整教程

灰阶中性（商务浅色）（mo-gray） · 灰墨 MoH_UI

冷调商务 CRM 客户管理整页。冷灰白三层底 + 金属深灰主色 + 低饱和石墨蓝强调，客户阶段看板、跟进时间线与销售漏斗全部用 daisyUI 组件拼装、零依赖；挂 data-theme="mo-gray" 即整站换肤，适合企业级经营管理后台。

来源：灰墨二创主题（MIT）

在线整页案例：https://noii-y.github.io/moh-ui/themes/mo-gray/demo.html

用法一：照着整页做一个同款（推荐，复现效果最接近）

下面是该主题完整、可直接运行的整页源码（零依赖，保存为 .html 双击即可看）。让 AI 先 1:1 还原结构与视觉，再替换成你的业务内容；页面顶部「复制 AI 指令」会把含本源码的完整指令复制成纯文本，不联网也能复现。

换成你自己的业务时必须守住的视觉特征

  • 全页无彩色主色：primary 是金属深灰 #2b2b31（主按钮「新建客户」深灰底白字、品牌方块、菜单选中态），不是蓝也不是死黑；整站唯一带色相的是低饱和石墨蓝 accent #4a6fa5，只做头像与数据高亮的点缀。
  • 冷灰白三层：页面底 #f4f4f6、白卡 #ffffff、边框 #ececef；客户小卡一律白底 + 1px 灰边 + 0.45rem 圆角，不用投影、不用彩色底块，企业级克制。
  • 人物头像全用灰阶字标：secondary 中灰 #71717a、accent 石墨蓝、neutral 近深灰三种轮换的圆形姓氏首字，不出现真人照片与彩色卡通。
  • 优先级与阶段用语义软徽章分级：高优先级 error 红、中 warning 琥珀、低 / 交付中 neutral 灰、已成交 success 绿；其余正文信息一律灰阶，不新增别的彩色标签。
  • 销售漏斗用四段 progress 递进配色：primary 深灰 → secondary 中灰 → accent 石墨蓝 → neutral 近黑，每段右侧对齐百分比；不画彩色金字塔，纯横向进度条。
  • 跟进时间线用 daisyUI timeline 竖线节点，节点图标是 currentColor 14px 线性 SVG（电话 / 上门 / 邮件 / 会议），描边随文字色，零外链零彩色插画。
  • 窄屏 ≤900px：客户阶段看板整板（min-width 940px）保持横向滑动、不折成单列；两栏（时间线 + 漏斗）塌成单列，侧栏菜单横向换行。

用法二：只给已有项目换肤

① 在 <head> 引入 daisyUI 5 底座：

<link rel="stylesheet" href="https://noii-y.github.io/moh-ui/vendor/daisyui.css">
<link rel="stylesheet" href="https://noii-y.github.io/moh-ui/themes/mo-gray/tokens.css">

② 在 <html> 挂 data-theme="mo-gray"，组件类名一行都不用改。上面的 tokens.css 覆盖 [data-theme="mo-gray"] 下的全部 --color-* 变量。

③ 本主题完整变量（要改颜色就覆盖这些变量，不要在组件里硬编码色值）：

/*! 灰墨 mo-gray · 冷调商务（浅色）—— 灰阶克制 CRM 后台主题
   覆盖 daisyUI 5 主题变量（MIT，daisyUI © Pouya Saadeghi）。
   用法：项目已引入 daisyUI 后，<link> 本文件，并在 <html data-theme="mo-gray"> 即整站换肤。
   灵感来源：shadcn Graphite 石墨灰的冷调商务气质（仅风格参考，非品牌素材）。 */

[data-theme="mo-gray"] {
  /* 底与纸：浅灰白三层，层次靠明度与细描边区分 */
  --color-base-100: #f4f4f6;
  --color-base-200: #ffffff;
  --color-base-300: #ececef;
  --color-base-content: #1f1f24;

  /* 主色：金属深灰（主操作与选中态，不做大面积黑色块） */
  --color-primary: #2b2b31;
  --color-primary-content: #ffffff;

  /* 次色 / 强调色：中灰与低饱和冷青石墨蓝，用于头像、标签与数据高亮 */
  --color-secondary: #71717a;
  --color-secondary-content: #ffffff;
  --color-accent: #4a6fa5;
  --color-accent-content: #ffffff;

  --color-neutral: #1f1f24;
  --color-neutral-content: #ffffff;

  /* 语义色：标准可读色，content 白 */
  --color-info: #0284c7;
  --color-info-content: #ffffff;
  --color-success: #16a34a;
  --color-success-content: #ffffff;
  --color-warning: #d97706;
  --color-warning-content: #ffffff;
  --color-error: #dc2626;
  --color-error-content: #ffffff;

  /* 圆角 / 尺寸 / 边框：小圆角、细边框，企业级克制取向 */
  --radius-selector: 0.3rem;
  --radius-field: 0.25rem;
  --radius-box: 0.45rem;
  --size-selector: 0.25rem;
  --size-field: 0.25rem;
  --border: 1px;
  --depth: 1;
  --noise: 0;
}

④ 组件全部走 daisyUI 语义类（btn / card / table / input 等），不要硬编码颜色。
