灰墨 MoH_UIAI 组件指令 完整教程

粉彩（柔和浅色）（mo-pastel） · 灰墨 MoH_UI

圆润亲和在线教育课程后台整页。微粉暖白底 + 深莓果主色 + 淡紫暖杏点缀，学员统计、课程卡片网格、本周排课表与待批作业全部用 daisyUI 组件拼装、零依赖；挂 data-theme="mo-pastel" 即整站换肤，适合教育 / 生活服务 / 健康类产品后台。

来源：灰墨二创主题（MIT）

在线整页案例：https://noii-y.github.io/moh-ui/themes/mo-pastel/demo.html

用法一：照着整页做一个同款（推荐，复现效果最接近）

下面是该主题完整、可直接运行的整页源码（零依赖，保存为 .html 双击即可看）。让 AI 先 1:1 还原结构与视觉，再替换成你的业务内容；页面顶部「复制 AI 指令」会把含本源码的完整指令复制成纯文本，不联网也能复现。

换成你自己的业务时必须守住的视觉特征

  • 微粉暖白三层底：base-100 #faf7f8 页面、base-200 #ffffff 侧栏与卡片、base-300 #f5f0f2 封面条与分隔线；正文文字用深莓褐 #45343d 而非纯黑，整体低饱和不刺眼。
  • 全库大圆角：--radius-box 1.25rem、--radius-field 0.75rem、--radius-selector 1rem，卡片、按钮、头像、输入框都要圆；禁止直角、厚黑边与硬阴影。
  • 深莓果主色 #8e3b5e 白字，只给主按钮、进度条（progress-primary）、菜单选中态与通知角标；淡紫 #8a63b8 与暖杏 #e8927c 只做点缀（封面图标色、头像底色），绝不大面积铺色。
  • 课程卡片封面固定为「低饱和 base-300 色块 + 居中 42px 线性图标」：图标 stroke 用 currentColor、按课程轮换 primary / secondary / accent 三个主题色；不用照片、不用渐变、不用 emoji。
  • 学生头像（圆形 .av）底色按 primary / secondary / accent / neutral 轮换、文字读对应 *-content 变量；保持圆润亲和，不要用方形或描边头像。
  • 语义色只在提醒处使用：success 绿报增长、warning 橙标「待批 / 未开始」、error 红表出错；日常正文保持莓褐与 0.65 灰，不要整页挂满彩色徽章。
  • ≤900px 侧栏退化为顶部横向换行菜单、排课表（min-width 760px）保持容器内横向滚动不折行，课程网格 auto-fill 自然降为单列，整页不横向溢出。

用法二：只给已有项目换肤

① 在 <head> 引入 daisyUI 5 底座：

<link rel="stylesheet" href="https://noii-y.github.io/moh-ui/vendor/daisyui.css">
<link rel="stylesheet" href="https://noii-y.github.io/moh-ui/themes/mo-pastel/tokens.css">

② 在 <html> 挂 data-theme="mo-pastel"，组件类名一行都不用改。上面的 tokens.css 覆盖 [data-theme="mo-pastel"] 下的全部 --color-* 变量。

③ 本主题完整变量（要改颜色就覆盖这些变量，不要在组件里硬编码色值）：

/*! 灰墨 mo-pastel · 粉彩柔和（浅色）—— 圆润亲和在线教育后台主题
   覆盖 daisyUI 5 主题变量（MIT，daisyUI © Pouya Saadeghi）。
   用法：项目已引入 daisyUI 后，<link> 本文件，并在 <html data-theme="mo-pastel"> 即整站换肤。
   灵感来源：shadcn Marshmallow 粉彩圆润气质（仅风格参考，非品牌素材）。 */

[data-theme="mo-pastel"] {
  /* 底与纸：微粉暖白三层，柔和不刺眼 */
  --color-base-100: #faf7f8;
  --color-base-200: #ffffff;
  --color-base-300: #f5f0f2;
  --color-base-content: #45343d;

  /* 主色：深莓果（主操作与选中态，白字对比充足） */
  --color-primary: #8e3b5e;
  --color-primary-content: #ffffff;

  /* 次色 / 强调色：柔和淡紫与暖杏蜜桃，用于装饰与数据高亮 */
  --color-secondary: #8a63b8;
  --color-secondary-content: #ffffff;
  --color-accent: #e8927c;
  --color-accent-content: #5c2a1a;

  --color-neutral: #45343d;
  --color-neutral-content: #ffffff;

  /* 语义色：标准可读色，content 白 */
  --color-info: #0284c7;
  --color-info-content: #ffffff;
  --color-success: #16a34a;
  --color-success-content: #ffffff;
  --color-warning: #d97706;
  --color-warning-content: #ffffff;
  --color-error: #dc2626;
  --color-error-content: #ffffff;

  /* 圆角 / 尺寸 / 边框：大圆角、细边框，亲和圆润取向 */
  --radius-selector: 1rem;
  --radius-field: 0.75rem;
  --radius-box: 1.25rem;
  --size-selector: 0.25rem;
  --size-field: 0.25rem;
  --border: 1px;
  --depth: 1;
  --noise: 0;
}

④ 组件全部走 daisyUI 语义类（btn / card / table / input 等），不要硬编码颜色。
