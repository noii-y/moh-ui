灰墨 MoH_UIAI 组件指令 完整教程

新中式（mo-zhongshi） · 灰墨 MoH_UI

茶叶文创电商首页。米宣纸底 + 朱砂主色 + 墨褐文字 + 衬线留白，顶栏 + 水墨 hero + 分类 + 商品网格 + 品牌故事留白区；挂 data-theme="mo-zhongshi" 即整站换肤，页面全部使用 daisyUI 组件拼装、零依赖。

来源：灰墨二创主题（MIT）

在线整页案例：https://noii-y.github.io/moh-ui/themes/mo-zhongshi/demo.html

用法一：照着整页做一个同款（推荐，复现效果最接近）

下面是该主题完整、可直接运行的整页源码（零依赖，保存为 .html 双击即可看）。让 AI 先 1:1 还原结构与视觉，再替换成你的业务内容；页面顶部「复制 AI 指令」会把含本源码的完整指令复制成纯文本，不联网也能复现。

换成你自己的业务时必须守住的视觉特征

  • 米宣纸三层底：base-100 #f6f3ec 页面、base-200 #fffdf8 卡片与 hero 画框、base-300 #efe9dd 商品图区；正文墨褐 #3f3730、辅助字 muted #756a58；卡片分隔只用 1px 暖米色细线 #e0d8c6（hover 加深 #c9bda3），禁止粗边框、投影，圆角控制在 --radius-box 0.375rem 以内。
  • 品牌名、hero 大标题、区块标题与品牌故事正文用宋体衬线栈（"Songti SC","STSong","SimSun",serif）并加 2~4px 字距；导航、按钮、商品名等正文仍用无衬线；标题行距宽松（hero line-height 1.3、故事正文 2.4）。
  • 朱砂主色 #c23b22 白字只给主按钮、商品价格、kicker 小标题（13px / 字距 4px）与印章；茶褐 #8a6d4a 与青瓷 #6b8e7f 只做次色点缀，绝不大面积铺红。
  • 品牌印章是 30px 朱砂方块 + 白字衬线单字（border-radius 4px），出现在 logo 位与品牌故事收尾处；不用 emoji、不用英文花体 logo。
  • 所有插画一律墨褐 #756a58 单色、stroke-width 1.5~1.6 的线性 SVG（hero 远山茶舟圆日、商品区杯罐礼盒），画在米白或 base-300 底上；不用彩色照片、不用渐变、不用霓虹。
  • 品牌故事区靠留白撑气质：上下 80px 留白 + 一条 56px 长的 1px 米色细线 + 居中衬线大字，不堆色块。
  • ≤860px hero 双栏塌为单列、分类方块 5 列塌为 2 列；≤560px 顶栏搜索框与购物车整行堆叠（nav-right 占满宽度），整页不横向溢出。

用法二：只给已有项目换肤

① 在 <head> 引入 daisyUI 5 底座：

<link rel="stylesheet" href="https://noii-y.github.io/moh-ui/vendor/daisyui.css">
<link rel="stylesheet" href="https://noii-y.github.io/moh-ui/themes/mo-zhongshi/tokens.css">

② 在 <html> 挂 data-theme="mo-zhongshi"，组件类名一行都不用改。上面的 tokens.css 覆盖 [data-theme="mo-zhongshi"] 下的全部 --color-* 变量。

③ 本主题完整变量（要改颜色就覆盖这些变量，不要在组件里硬编码色值）：

/*! 灰墨 mo-zhongshi · 新中式（浅色）—— 文创 / 茶叶电商首页主题
   覆盖 daisyUI 5 主题变量（MIT，daisyUI © Pouya Saadeghi）。
   用法：项目已引入 daisyUI 后，<link> 本文件，并在 <html data-theme="mo-zhongshi"> 即整站换肤。
   气质：米宣纸底、朱砂主色、墨褐文字、青瓷点缀、克制留白。
   灵感来源：中式宋明美学与茶饮品牌页面（仅风格参考，非品牌素材）。 */

[data-theme="mo-zhongshi"] {
  color-scheme: light;

  /* 底与纸：米宣纸三层，层次靠暖明度 */
  --color-base-100: #f6f3ec;
  --color-base-200: #fffdf8;
  --color-base-300: #efe9dd;
  --color-base-content: #3f3730;

  /* 主色：朱砂 */
  --color-primary: #c23b22;
  --color-primary-content: #ffffff;

  /* 次色：茶褐 / 赭石 */
  --color-secondary: #8a6d4a;
  --color-secondary-content: #ffffff;

  /* 强调色：青瓷低饱和绿 */
  --color-accent: #6b8e7f;
  --color-accent-content: #ffffff;

  --color-neutral: #3f3730;
  --color-neutral-content: #ffffff;

  /* 语义色 */
  --color-info: #3a6ea5;
  --color-info-content: #ffffff;
  --color-success: #16a34a;
  --color-success-content: #ffffff;
  --color-warning: #d97706;
  --color-warning-content: #ffffff;
  --color-error: #dc2626;
  --color-error-content: #ffffff;

  /* 圆角 / 边框：中性小圆角、1px 细边 */
  --radius-selector: 0.375rem;
  --radius-field: 0.25rem;
  --radius-box: 0.375rem;
  --size-selector: 0.25rem;
  --size-field: 0.25rem;
  --border: 1px;
  --depth: 0;
  --noise: 0;
}

④ 组件全部走 daisyUI 语义类（btn / card / table / input 等），不要硬编码颜色。
