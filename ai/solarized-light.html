Solarized Light（纸感护眼）（solarized-light） · 灰墨 MoH_UI

健康档案 / 预约挂号整页。米纸底色 #fdf6e3 配深青墨文字，低亮度差、长时间阅读不累眼；挂 data-theme="solarized-light" 即整站换肤，页面全部使用 daisyUI 组件拼装、零依赖。

来源：Solarized（MIT） · 上游色板

在线整页案例：https://noii-y.github.io/moh-ui/themes/solarized-light/demo.html

用法一：照着整页做一个同款（推荐，复现效果最接近）

下面是该主题完整、可直接运行的整页源码（零依赖，保存为 .html 双击即可看）。让 AI 先 1:1 还原结构与视觉，再替换成你的业务内容；页面顶部「复制 AI 指令」会把含本源码的完整指令复制成纯文本，不联网也能复现。

换成你自己的业务时必须守住的视觉特征

  • 底三层是经典 Solarized 米纸：base-100 #fdf6e3（base3）页面底、base-200 #eee8d5（base2）侧栏与外卡片、base-300 #e3dccb 内卡描边与图标底；正文用 base02 深青墨 #073642，明度差刻意压低、长时间阅读不累眼。绝不能出现纯白 #fff 配纯黑 #000 的高对比组合。
  • 招牌主色是 Solarized 蓝 #268bd2（primary，配米纸字 #fdf6e3），只留给主操作按钮、选中态 menu-active、primary 徽章；辅助色固定 Solarized 六色：violet #6c71c4、cyan #2aa198、green #859900、yellow #b58900、red #dc322f，不要换成别的蓝绿。
  • 状态一律 badge-soft 浅盘 + 深字（各 *-content 已配好）：可约=绿、号源紧张=黄、已约=蓝、约满/休诊/取消=灰青 neutral #93a1a1；不做实心高饱和状态块。
  • 医疗后台信息密度：表格 13px、表头降到 .6 透明度弱化，外卡片 bg-base-200 rounded-box、内层科室卡用 bg-base-100 加 1px base-300 细描边；科室图标是 base-300 圆角方块底 + primary 蓝 currentColor 线性 SVG。
  • 图标全部 currentColor 单色线性 SVG（心电图、十字、笑脸、眼睛、牙齿、树叶轮廓），stroke 约 2，不用彩色插画、不用 emoji、不用照片。
  • 圆角比一般主题稍方：--radius-field .375rem、--radius-selector .5rem、--radius-box .625rem；--border:1px、--depth:1、--noise:0，细边无阴影。
  • 窄屏口径：≤900px 左侧 220px 栏退化为顶部横向菜单行（分隔线从竖边改横边），指标卡 auto-fit 折行，宽表 overflow-x 横滑，不硬塞不缩字。

用法二：只给已有项目换肤

① 在 <head> 引入 daisyUI 5 底座：

<link rel="stylesheet" href="https://noii-y.github.io/moh-ui/vendor/daisyui.css">
<link rel="stylesheet" href="https://noii-y.github.io/moh-ui/themes/solarized-light/tokens.css">

② 在 <html> 挂 data-theme="solarized-light"，组件类名一行都不用改。上面的 tokens.css 覆盖 [data-theme="solarized-light"] 下的全部 --color-* 变量。

③ 本主题完整变量（要改颜色就覆盖这些变量，不要在组件里硬编码色值）：

/*! 灰墨 solarized-light · 纸感护眼——Solarized 浅色主题
   覆盖 daisyUI 5 主题变量（MIT，daisyUI © Pouya Saadeghi）。
   配色取自 Ethan Schoonover 的 Solarized 色板（MIT，https://github.com/altercation/solarized#the-values）。
   用法：项目已引入 daisyUI 后，<link> 本文件，并在 <html data-theme="solarized-light"> 即整站换肤。 */

[data-theme="solarized-light"] {
  color-scheme: light;

  /* 底与纸：base3 / base2 / 再深一档，米纸三层，层次靠明度 */
  --color-base-100: #fdf6e3;
  --color-base-200: #eee8d5;
  --color-base-300: #e3dccb;
  --color-base-content: #073642; /* base02 深青墨，保证亮底下对比 */

  /* 主色：Solarized blue（只留给主操作与选中态） */
  --color-primary: #268bd2;
  --color-primary-content: #fdf6e3;

  /* 次色 / 强调色：violet 与 cyan */
  --color-secondary: #6c71c4;
  --color-secondary-content: #fdf6e3;
  --color-accent: #2aa198;
  --color-accent-content: #073642;

  --color-neutral: #93a1a1; /* base1 灰青 */
  --color-neutral-content: #073642;

  /* 语义色：cyan 信息 / green 成功 / yellow 警告 / red 错误，均配好对比 */
  --color-info: #2aa198;
  --color-info-content: #073642;
  --color-success: #859900;
  --color-success-content: #002b36;
  --color-warning: #b58900;
  --color-warning-content: #073642;
  --color-error: #dc322f;
  --color-error-content: #fdf6e3;

  /* 圆角 / 尺寸 / 边框：中性圆角、细边框，长文阅读取向 */
  --radius-selector: 0.5rem;
  --radius-field: 0.375rem;
  --radius-box: 0.625rem;
  --size-selector: 0.25rem;
  --size-field: 0.25rem;
  --border: 1px;
  --depth: 1;
  --noise: 0;
}

④ 组件全部走 daisyUI 语义类（btn / card / table / input 等），不要硬编码颜色。
