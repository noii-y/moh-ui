切换状态（swap） · 灰墨 MoH_UI

纯 CSS label+checkbox 双图标切换，覆盖旋转/翻转/默认选中/swap-active 强制 on 态，内联 SVG 收藏、显隐密码、昼夜、静音等真实场景。

分类：反馈　｜　来源：daisyUI（MIT） · 官方文档　｜　依赖：无（零依赖）

给 AI 的实现指令

请用 daisyUI 5（纯 CSS 类、class 版 HTML，不依赖框架、无需构建）帮我实现：商品详情页收藏切换按钮。

【场景】商品详情页或列表项上的收藏按钮：同一个位置，未收藏是空心星，已收藏是实心黄星，点一下纯 CSS 切换。 【怎么排】

  • 结构：外层 <label class="swap swap-rotate">，里面依次是隐藏的 <input type="checkbox" aria-label="收藏商品" />、<div class="swap-off"> 空心星图标、<div class="swap-on"> 实心星图标。
  • 两副图标叠在同一格，靠 checkbox 的 :checked 切透明度，不要写 JS、不要加 onclick。
  • 已收藏的星用 text-warning 染色（主题语义色，不写死色值）；图标统一 h-9 w-9。
  • 静态展示时并排两个示例：一个 input 不加 checked（未收藏），一个 input 加 checked（已收藏），各自下方一行小字标注「收藏」「已收藏」。

【精确规格】

  • 默认态放 swap-off，选中态放 swap-on；要默认选中就给 input 加 checked，或在 label 上加 swap-active。
  • 切换动画二选一：swap-rotate（旋转 45°，收藏/静音用）、swap-flip（垂直翻面，显示/隐藏密码用）；不加修饰类直接淡入淡出。
  • 图标全部用内联 SVG，禁止外链图、禁止第三方品牌图标。
  • 文案写真实中文动作，不出现颜色名；checkbox 必须带 aria-label 说明用途。

【灰墨审美硬边界（必须遵守）】

  • 控件高度统一 32px，同组控件间距 8px，所有间距用 8px 网格（4/8/12/16/24）。
  • 正文 14px，页面标题不超过 24px，同一屏字号不超过 5 级；数字/金额用等宽数字。
  • 所有可点元素要有 hover 与 focus 态（focus 用 2px 主色描边）；禁用优先用 disabled 属性（透明度 0.5 + not-allowed）。
  • 正文对比度 ≥ 4.5:1；主色全库唯一，状态色语义化（成功绿/警告橙/危险红）；不要大面积高饱和撞色、大面积渐变、多层阴影，不要用 emoji 当图标（用单色 SVG）。
  • 动效不超过 200ms，不做装饰性的闪烁、缩放、弹跳入场动画；组件自带的功能性状态动画除外（loading 旋转、status 状态点 ping/bounce、toggle/swap 切换、collapse 展开等），保留官方默认即可，不要再额外叠加装饰动画。
  • 颜色全部走 CSS 变量（daisyUI 主题变量），不要写死颜色。
