代码块 Code Block

教程与文档里的代码块：深色窗口、语言标签、一键复制、真语法高亮。基于 highlight.js 渲染，高亮配色跟随主题。下面先给一个可以直接拿走的成品，再列出其它形态。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）；本组件还需额外引入一行 highlight.js CDN 脚本，地址就在下面成品区顶部（common 版含常用语言）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 把 <code> 里的内容换成你的代码，并在 class 里写对语言名（language-javascript / language-python / language-shell）；切换主题后高亮颜色自动跟着变。

教程文档里的 JavaScript 代码块

深色窗口：顶栏左边写语言名「JavaScript」，右边一个小「复制」按钮；下面是真实可读的 JS 片段——如何读 daisyUI 主题变量来初始化图表，和图表卡正好呼应。

JavaScript 
// 读 daisyUI 主题变量，初始化折线图
const css = getComputedStyle(document.documentElement);
const primary = css.getPropertyValue("--color-primary").trim();

const chart = echarts.init(document.getElementById("chart-trend"));
chart.setOption({
  xAxis: { type: "category", data: ["5月", "6月", "7月"] },
  yAxis: { type: "value" },
  series: [{ type: "line", data: [820, 932, 901], lineStyle: { color: primary } }]
});
window.addEventListener("resize", () => chart.resize());

使用指南

和 mockup-code 怎么选

纯展示几行命令、不想引 CDN，用零依赖的 mockup-code（daisyUI 自带）；要真语法高亮、要一键复制按钮，用本组件（依赖 highlight.js CDN）。别为了三行命令多加载一个库。

不引 hljs 官方主题 CSS

highlight.js 只引核心库，它自带的浅色主题样式表不要加载；关键字、字符串、注释、数字的配色写在组件内联 <style> 里，全部取 daisyUI 变量（主色=关键字、成功绿=字符串、警告橙=数字、secondary=函数名），深浅主题都协调。

语言类要写对

<code> 上加 language-javascript / language-python / language-shell，hljs 按这个类名选语法规则；写错了就没有高亮。展示 HTML 代码时，尖括号必须转义成 &lt; &gt;。

复制按钮

用 navigator.clipboard.writeText 复制 <code> 的文本，失败时兜底 execCommand("copy")；按钮加 aria-label，复制成功后短暂显示「已复制」再还原。

长行不换行

pre 保持默认不换行，外层 overflow-x-auto 横向滚动；换行打散缩进比滚动更难看。
