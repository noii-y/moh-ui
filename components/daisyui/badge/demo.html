徽标 Badge

一个小圆角的小标签，用来给商品、状态、数字打标记：新品、热卖、包邮、未读数都是它。下面先给一个商品标签组成品，再看尺寸、风格和带图标的写法。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 改颜色加 badge-*，改大小加 badge-xs 到 badge-xl，切换主题后自动跟随。

五档尺寸

默认大小最通用；放导航、按钮里用 badge-sm 或 badge-xs，大标题旁才用 badge-lg 以上。

极小 小 默认 大 超大

描边、虚线、柔和三种风格

实心标签最抢眼；一排次要标签多时改用描边（badge-outline）或柔和（badge-soft）降低视觉重量；badge-dash 虚线描边专门表示「等待中、待处理」。

描边 柔和 待审核 幽灵

带图标的标签

标签里放一个小 SVG 图标，能让人在扫一眼列表时更快认出含义，比如「已发货」配对勾、「退款中」配警告三角。

已发货 退款审核中 支付失败

嵌在按钮里的数字角标

把小徽章放进按钮、标签页里，表示「还有这么多件事等着你」：新消息、待办数量，数字超过 99 就写 99+。

使用指南

标签上写的是含义

徽章里永远写真实业务词：新品、热卖、售罄、包邮、待审核；不要写颜色名，也不要写 Primary 这种类名当文案。

颜色怎么选

  • badge-primary：最重要的新标记（新品、新上线）。
  • badge-secondary：强调但不紧急（热卖、热门）。
  • badge-neutral / badge-ghost：中性状态（售罄、已归档）。
  • badge-success / warning / error / info：只在结果含义明确时用。

密度控制

一排标签最多四五个，多了用描边或柔和风格；一个商品身上同时挂「新品 + 热卖 + 包邮 + 8 折 + 会员专享」五个实心彩色标签等于没有标签。

图标与数字

标签里的小图标统一 h-4 w-4；数字角标超过 99 一律显示 99+，不要让它撑宽布局。
