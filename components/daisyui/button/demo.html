按钮 Button

用于触发动作或选择。以下示例结构搬运自 daisyUI 官方文档，已做零依赖改造，可直接复制使用。

来源：daisyui.com/components/button（MIT）

颜色

默认 / 主 / 次 / 强调 / 中性，以及信息、成功、警告、错误语义色；幽灵按钮与链接按钮。

尺寸

btn-xs / btn-sm / 默认 / btn-lg / btn-xl。

描边按钮

btn-outline：透明底 + 彩色描边，适合次要操作。

虚线按钮

btn-dash：虚线描边，常用于"新增一项"。

激活状态

btn-active：表现为被按下的样式，用于导航中当前项等。

禁用

推荐用 disabled 属性；也可用 btn-disabled 类（需配合 aria-disabled）。

方形与圆形（图标按钮）

btn-square 为正方形，btn-circle 为圆形，内部放图标。

带图标

图标可放在文字前或后，使用 h-5 w-5 控制大小。

加载中

配合 loading 组件，表示提交中。

加宽与整行

btn-wide 增大水平内边距；btn-block 占满容器宽度。

玻璃拟态（置于深色背景上）

btn glass：半透明毛玻璃效果，适合放在图片或深色背景上。
