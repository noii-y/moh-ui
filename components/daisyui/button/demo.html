按钮 Button

点击后触发一个动作或提交一张表单，是界面里最常用的操作入口。下面先给一个可以直接拿走的成品，再列出各种配色、尺寸和状态供参考。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 改颜色、尺寸只改 class 即可；切换主题后，整套按钮颜色会自动跟着变。
成品示例 · 拿来即用

一张表单底部的操作栏

一个操作区只放一个主按钮：实心的「保存修改」是主操作，其余用默认或纯文字弱化；最后的「删除」用红色提示风险。

首选「复制 AI 提示词」整段发给你的 AI，它会按你的项目生成；想直接粘贴代码、双击预览，再用「复制成品 HTML」。

配色：按钮上写的是动作

颜色用来表达动作的轻重与含义，按钮文字仍写具体动作。主色用于主操作；中性色用于次要操作；成功 / 警告 / 错误只在结果含义明确时使用。

纯文字按钮和链接按钮

无底框（ghost）弱化成一行文字，用于最不显眼的操作；链接（link）样式用于看起来像链接的操作。

尺寸

共五档，默认大小最通用；小按钮适合紧凑的工具条，超大按钮适合移动端的关键转化。

描边按钮

透明底加一圈描边，适合一排并列的次要操作，视觉上比实心按钮更轻。

虚线按钮

虚线描边专门用来表示「新增一项」，例如新增成员、添加分组。

当前选中项

加 active 表示被按下 / 选中，常用于「日 / 周 / 月」这一类分段切换。

方形与圆形图标按钮

只有图标、没有文字时使用，方形适合工具条，圆形适合头像区或悬浮操作；记得用 aria-label 说明用途。

带图标的文字按钮

图标放在文字前或后，统一用 h-5 w-5 控制大小，能帮用户更快认出动作。

提交中（加载状态）

点击提交后显示加载圈，并禁用按钮防止重复提交。

加宽与整行

加宽让按钮更舒展；整行占满容器宽度，适合手机端登录、提交表单。

禁用

条件不满足时禁用，比如表单没填完不能提交。推荐直接用 disabled 属性。

毛玻璃（放在图片或深色背景上）

加 glass 得到半透明毛玻璃效果，适合叠在图片、视频或彩色背景上。

使用指南

一个区域只放一个主按钮

实心主色按钮在一个操作区里只出现一个，其余操作改用默认、描边或纯文字按钮，否则用户找不到重点。

颜色怎么选

  • btn-primary：保存、提交、确认这类主操作。
  • btn-secondary / btn-neutral：次要操作。
  • btn-accent：需要强调、带一点鼓励意味的动作。
  • btn-success / btn-warning / btn-error：仅用于成功、警告、错误含义明确的动作，别为了好看乱用红色。
  • btn-ghost（无底框）、btn-link（链接式）：最弱化的操作。

危险动作

删除、清空等不可恢复操作使用 btn-error，建议配合弹窗二次确认，避免误触。

图标与可访问性

纯图标按钮必须加 aria-label；加载期间用 loading 并禁用按钮；禁用优先用 disabled 属性。键盘焦点自带高亮描边，不要去掉。
