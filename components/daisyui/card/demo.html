卡片 Card

把一组相关内容收拢成一块：定价套餐、商品、用户资料都能用它承载。下面先给一个可以直接拿走的三档定价成品，再列出各种形态供参考。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 改边框、尺寸只改 class 即可；切换主题后，整套卡片颜色会自动跟着变。

五档尺寸

card-xs 到 card-xl 只改变内边距和文字密度，不改变宽度——宽度由你外层的网格或 w-* 类控制。看板上的小卡用 card-sm，定价页用默认即可。

使用指南

一张卡只讲一件事

卡片是「内容分组」，不是页面布局：一张卡里只放同一个主题的内容（一个商品、一个套餐、一个用户）。需要并排展示多项时，外面套 grid 网格，不要把内容硬塞进同一张卡。

主推档怎么突出

定价页要推某一档，用「徽标 + 稍重阴影 + 一圈主色描边」三件套即可，不要给主推档换一整块高饱和底色——浅底黑字永远比深底白字好读。

不含的功能怎么写

套餐对比表里，「该档不含」的功能用删除线 + 半透明弱化，而不是干脆不列——访客需要先知道「我多花的钱买到了什么」。

图片与零依赖

商品图放 figure，接图时用 <img>；没有图时用 bg-base-200 色块 + 单色 SVG 占位，不要外链图片、不要硬编码十六进制色值。

动作按钮

卡内按钮统一放 card-actions 里，靠右（justify-end）或居中（justify-center）二选一；整宽按钮（btn-block）适合定价页这种「一张卡一个动作」的场景。
