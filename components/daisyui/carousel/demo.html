轮播 Carousel

在一条横向轨道上并排展示多张卡片，用户左右滑动翻看，常见于商品推荐、Banner 广告。下面先给一个拿来即用的商品推荐横滑成品，再列出横幅、居中吸附、垂直轮播等形态。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 改卡片数量、一屏几张只改 carousel-item 的宽度类（w-1/2、w-1/3、w-full）；切换主题后颜色自动跟随。

使用指南

纯 CSS 能做什么

本成品的滑动靠浏览器原生触摸与滚轮横向滚动，吸附靠 scroll-snap，箭头和数字指示器靠锚点（href 指向对应 item 的 id）跳转——全程零 JavaScript，复制过去就能滑。

哪些功能必须加 JavaScript

  • 自动播放（定时切换下一张）；
  • 无限循环（滑到最后一张后回到第一张的无缝衔接）；
  • 拖拽跟手（鼠标按住卡片拖动，松手回弹）；
  • 根据滚动位置高亮当前箭头 / 当前数字。

需要这些效果时，在自己的项目里引入一个轮播库或手写几十行 JS；本组件不内置，保持零依赖。

图片怎么换成真实商品图

成品里图区是一个内联渐变占位块，替换成你的图片时，把图区 div 换成 <img>（加 w-full h-40 object-cover rounded-t-box），商品卡其余结构不用动。

手机端两条红线

  • 横滑只允许发生在 carousel 容器内部，不要给整页加横向滚动，也不要给 carousel 加 fixed 定位；
  • 一屏几张由 item 宽度决定：w-1/2 两张、w-1/3 三张、w-full 整屏一张。

关于「手机两张、桌面三张」

要在手机上一屏两张、桌面上自动变成一屏三张，需要响应式分数宽类（如 lg:w-1/3）。当前补丁层只提供静态分数宽，本版先用 w-1/2 做主成品、w-1/3 做变体演示；补齐响应式类后，把主成品 item 改为 w-1/2 lg:w-1/3 即可。

可访问性

箭头是纯图标按钮，必须加 aria-label；数字指示器同样加 aria-label 说明第几张。键盘用户可以用 Tab 聚焦箭头后回车跳转。
