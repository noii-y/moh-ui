复选框 Checkbox

勾选或取消一个或多个独立选项，可多选、互不影响。下面先给一个注册流程里可以直接拿走的勾选区，再列出各种尺寸、分组和状态供参考。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 改颜色、尺寸只改 class 即可；切换主题后，整套勾选框颜色会自动跟着变。

注册流程里的协议与偏好勾选区

提交前必须勾选「同意协议」，用主色标出但不默认勾选、让用户主动同意；可选偏好保持中性；每一项都用 label 包住，点文字也能勾，组尾放注册按钮收尾。

注册确认
首选「复制 AI 提示词」整段发给你的 AI，它会按你的项目生成；想直接粘贴代码、双击预览，再用「复制成品 HTML」。

基础勾选态

最朴素的两种状态：勾选（带 checked）和未勾选。单独使用时旁边一定要配文字说明是勾什么。

点文字也能选

用 label 把勾选框和文字包在一起，整行都可点，比只有小方框好操作得多；想默认勾上哪项就加 checked。

分组：设置页里的多选清单

一组相关选项放进 fieldset 并写 legend，屏幕阅读器会把它读作这一组的标题；适合通知渠道、权限清单这类设置项。

通知方式

半选状态（indeterminate）

父级勾选框用于「全选」：子项只勾了一部分时显示横线半选。半选状态需用 JS 设置 indeterminate 属性（本页仅此处用一行 JS），刷新后会消失。

尺寸

共五档，默认大小最通用；小尺寸适合紧凑表格行，大尺寸适合移动端设置页。

语义状态色

这一排是 daisyUI 的语义状态色：从主色到错误色，分别对应主操作、强调、成功、警告、错误等含义。实际使用时按需取用，不要为了好看全用醒目颜色。

禁用

条件不满足或权限不足时禁用；禁用且选中表示「这项已经由系统设定好、用户不能改」。用 disabled 属性。

使用指南

复选框还是单选框

各选项互相独立、可同时多选（通知渠道、偏好设置）用复选框；互斥只能选一个（性别、付款方式）用单选框 Radio。

一定让文字可点

每一项都用 label.label.cursor-pointer 包住 input 和文字，点击区域从方框扩大到整行，手机上尤其重要。

分组用 fieldset

一组相关选项用 fieldset.fieldset 加 legend 包起来，读屏软件会自动把 legend 读作组标题。

半选只用于父子全选

indeterminate 只在「父框控制一组子框」时出现（子项部分选中），且必须由 JS 设置；不要用它表达普通状态。

可访问性与禁用

键盘 Tab 聚焦勾选框后用空格切换选中，焦点描边不要去掉；禁用优先用 disabled 属性，它会同时阻止点击和聚焦。
