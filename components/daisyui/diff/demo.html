对比 Diff

左右并排展示两张图的差别——设计改版前后、照片两种调色、两张稿图，中间一条分隔线左右拖动即可对照。下面先给一个可以直接拿走的成品，再看图片与文字两种用法。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 把占位的渐变 SVG 换成你自己的两张 <img>；想要分隔线真能拖动，再补一小段 JS（指南里有说明）。
成品示例 · 拿来即用

设计改版「优化前 / 优化后」

给客户看改版效果最直观的方式：左半边是拥挤、低饱和的旧稿，右半边是留白充足、主按钮醒目的新稿，中间白色分隔线一压，差别一眼可见。两张稿这里用内联渐变加手绘线框示意，换成你的真实设计稿 <img> 即可。

首选「复制 AI 提示词」整段发给你的 AI，它会按你的项目生成；想直接粘贴代码、双击预览，再用「复制成品 HTML」。

图片对比：同一张照片的两种调色

同一个山景轮廓，左边暖黄黄昏、右边蓝紫夜幕，中间分隔线压在正中。这就是最经典的用法——两张等大的图叠在一起，拖动分隔线看差别。真实项目把两个 diff-item 里的渐变换成你的 <img>。

文字对比：一个大字从中间劈开

不只是图，文字也能对比：同一个超大字，左边是主色实心、右边是浅灰底，分隔线正好从笔画中间切过去，做标题、Logo 双方案对照很出效果。

使用指南

三段结构，缺一不可

外层 figure.diff，里面依次是 diff-item-1（左半边内容）、diff-item-2（右半边内容）、最后一个空的 diff-resizer。顺序不能换，diff-resizer 必须在最后。

静态展示就是 50%

纯 CSS 下分隔线默认停在正中间，左右各占一半，截图、卡片预览都能直接看到效果，不需要任何脚本。两个 diff-item 里放什么由你定：图片、渐变、整段大字都行。

想要分隔线真能拖动，补一小段 JS

daisyUI 的 diff-resizer 自带 resize: horizontal，但要让它在鼠标 / 触屏下顺畅拖动，真实项目里通常再补一段几十行的 JS（监听拖动、改分隔位置）。本组件保持零依赖零 JS，只做静态对比；需要可拖动版本时，按官方文档加这段脚本即可。

换成你的真实图片

把两个 diff-item 里的 SVG / 渐变占位换成 <img>，两张图一定要等大同比例（都用 aspect-video 这种容器比例约束），否则左右对不齐。

可访问性

外层 figure 加 tabindex="0" 可以用键盘聚焦；两个 diff-item 加 role="img" 和 aria-label，读屏才能说出左右分别是什么。
