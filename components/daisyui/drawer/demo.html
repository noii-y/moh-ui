抽屉侧栏 Drawer

后台系统的侧边导航：大屏时常驻在页面左侧，小屏或点按钮时从侧边滑出。常驻布局用纯 CSS 的 drawer；需要点按钮开合的浮层抽屉（导航、筛选）推荐用原生 <dialog>，自带焦点圈定、Esc 关闭、关闭后焦点返回。下面先给一个后台常驻侧栏成品，再看左侧滑出、右侧滑出、响应式与真实可点的键盘演示。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 常驻侧栏用 lg:drawer-open（大屏常显、窄屏收成抽屉）；点按钮开合的浮层抽屉用原生 <dialog> 加 showModal()，键盘行为原生可用，不需要写 JS 焦点陷阱。

使用指南

两种用法，先分清

常驻布局（后台整页左侧菜单）用纯 CSS 的 .drawer：结构三层——隐藏复选框 drawer-toggle、主内容 drawer-content、侧栏 drawer-side，配 lg:drawer-open 实现大屏常显、窄屏收成抽屉。点按钮开合的浮层抽屉（点「筛选」才从右侧滑出、点汉堡才出导航）推荐原生 <dialog>：键盘与焦点行为原生可用。

真实可点：dialog + showModal()

触发按钮 onclick="导航.showModal()"，抽屉是一个贴边的 <dialog class="drawer-m">（右侧加 drawer-m-end）。打开后浏览器原生做到：焦点圈进抽屉（Tab 跑不到背景）、背景内容 inert、按 Esc 关闭、关闭后焦点回到触发按钮，不用自己写焦点陷阱。右上角 ✕ 与底部按钮都包一层 <form method="dialog">，点任意一个自动关闭、无需 JS。

焦点落点（容易漏）

showModal() 默认聚焦抽屉里第一个可聚焦元素；本页把右上角 ✕ 放在标题旁、是第一个可聚焦项，所以打开后在触发按钮里顺手再 .focus() 到第一个菜单项（导航抽屉）或第一个日期框（筛选抽屉），焦点一进来就在主内容上，而不是落在关闭 ✕ 上。危险操作（删除、清空、重置已填表单）不要加 autofocus，免得误按回车直接触发。每个 <dialog> 用 aria-labelledby 指向抽屉标题，读屏会念出抽屉名。

抽屉的定位与动画

dialog.drawer-m 用 position:fixed;inset:0 auto 0 0 贴左全高（右侧 drawer-m-end 改 inset:0 0 0 auto），宽 300px、窄屏 max-width:85vw。滑入动画 ≤200ms 属于用户触发的功能性状态动画，被审美硬边界允许；务必同时写 @media (prefers-reduced-motion:reduce){…animation:none}，给减弱动效偏好的用户关掉。

纯 CSS 复选框法的局限

常驻侧栏与上面的静态演示用复选框法：它零 JS，但不支持 Esc、不锁背景、不圈焦点，只适合无 JS 环境、纯展示或常驻布局。所以静态写法必须补 role="dialog" aria-modal="true" aria-labelledby="标题id"。需要键盘可达的浮层抽屉，一律换成上面的 dialog 方案，不要在复选框法上硬补 JS。

关于本页的限高演示

详情页把常驻抽屉放进小舞台，并在 .drawer 与 .drawer-side 上加了演示用的内联高度约束（否则侧栏会按设计铺满整屏 100dvh）；常驻成品用无条件 drawer-open 只是为了让卡片缩略图里也能看到侧栏。复制到真实项目时：去掉这些内联 style，把根上的 drawer-open 换成 lg:drawer-open。

侧栏菜单怎么排

侧栏里放 menu：当前页加 menu-active（同一时刻只一个）；带数量提示用 badge badge-sm；未开通的入口加 menu-disabled；子菜单直接在 <li> 里嵌套一个 <ul>。图标统一 h-5 w-5 单色 SVG。触发按钮加 aria-label，文案写真实动作（展开导航菜单 / 筛选条件）。
