下拉菜单 Dropdown

点一下按钮，在旁边展开一列菜单或一块卡片——顶栏头像的个人中心、「更多操作」都是它。下面先给一个顶栏头像下拉的成品，再列出卡片弹层、弹出方向和分组分隔等形态供参考。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 改弹出方向、菜单项只改 class 与文案；切换主题后，菜单底色自动跟着变。

使用指南

点击触发，零依赖

推荐的零依赖写法：外层 div.dropdown，触发元素用 <div tabindex="0" role="button">（Safari 对按钮聚焦有 bug，官方因此用 div），内容 <ul tabindex="-1" class="dropdown-content menu">。内容在触发元素聚焦时出现、失焦自动收起，键盘 Tab 可直达。

悬停触发要留点击兜底

加 dropdown-hover 可以同时支持鼠标悬停展开，但移动端没有悬停事件，仍必须保留上面的点击 / 聚焦写法，不要只为悬停写 JS。

方向与对齐

默认向下；靠近上边缘用 dropdown-top，靠近页面右边缘用 dropdown-end 让菜单与按钮右对齐、dropdown-left 侧向弹出。静态展示时加 dropdown-open 强制展开，并给容器留出足够高度，否则菜单会贴住下一个元素。

菜单项的规矩

菜单用 <ul class="menu">，一项一个 <li><a>；危险操作（退出登录）用 text-error；分组用 menu-title、分隔用 <hr class="divider">；一个菜单里最多一个当前高亮项。

推荐：popover 原生写法（焦点管理最完整）

上面「真实可点」变体是键盘可用场景的推荐做法：触发 <button popovertarget="菜单id" aria-haspopup="menu" aria-controls="菜单id">，菜单 <ul id="菜单id" popover role="menu" aria-labelledby="触发按钮id">。原生 popover 白送三件事：点菜单外面关闭（light-dismiss）、按 Esc 关闭、关闭后焦点回到触发按钮，不用自己写焦点陷阱。aria-expanded 用菜单上一行 toggle 监听同步即可。

焦点落点（容易漏）

打开时焦点落在第一项菜单项；↑/↓ 在菜单项间移动（就是上面那段十几行的键盘脚本），Tab 也能逐项走；关闭后焦点回到触发按钮。菜单项写 <a role="menuitem" tabindex="0">——a 不带 href 时默认不可聚焦，必须补 tabindex="0"，否则键盘进不去。

popover 与 CSS focus / details 怎么选

本页上方静态成品用的是零 JS 的 CSS focus 写法（tabindex="0" 聚焦展开、失焦收起）：它最轻，但不锁定背景、没有方向键，也不会在你点菜单外面时干净收起；<details> 能展开，却不会在点外部时收起、也不把焦点还给触发按钮。一旦菜单要求键盘可用、点外部关闭、Esc 关闭，就用 popover 写法，别在 CSS focus / details 上自己补焦点逻辑。
