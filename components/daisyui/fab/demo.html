悬浮动作按钮 FAB / Speed Dial

一个钉在屏幕角落的主按钮，聚焦或悬停时展开一圈常用动作（Speed Dial）。下面先给一个内容平台右下角「新建」展开三个动作的成品，再列出纯图标、花瓣形、单个按钮等形态。本页为了不遮挡文档，已把固定定位的 FAB 放进带边框的舞台里。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 真实项目里 .fab 默认就钉在视口右下角（fixed）；本详情页为了不盖住正文才改成 static 放进舞台，记得在你的页面里去掉那个 static。

纯图标垂直 Speed Dial

不带文字标签、只放单色图标，更省地方；靠 aria-label 说明每个动作。图标统一 h-6 w-6。

花瓣形（fab-flower）

加 fab-flower，子按钮沿四分之一圆弧形展开，适合动作稍多、又不想占满一竖列的场景；同样用 aria-label 标注每个图标。

单个悬浮按钮（没有 Speed Dial）

角落只放一个主按钮、不展开任何动作时，直接在 .fab 里放一个圆形按钮即可。

使用指南

主按钮为什么用 div 而不是 button

daisyUI 用 <div tabindex="0" role="button"> 做主按钮，是为了绕开 Safari 一个历史上 button 难以聚焦的 CSS bug；tabindex="0" 让它能被 Tab 聚焦，role="button" 让读屏软件知道这是个按钮。直接照抄即可。

展开靠 focus / hover，不需要写 JS

speed-dial 子按钮平时是隐藏的，当主按钮被键盘聚焦或鼠标悬停（:focus-within）时自动展开，纯 CSS 实现。本详情页为了在静态截图里也能看到子按钮，才额外加了一段演示样式强制展开——真实项目不要复制那段，也不要为此写任何展开 JS。

本页为什么把它放进舞台

真实 .fab 默认是 position:fixed、钉在视口右下角。组件详情页如果也让它钉住，会盖住正文和「复制」按钮，所以本页给它加了 static 取消固定、放进带边框的舞台。你在自己页面里使用时，去掉这个 static，让它回到视口右下角即可。

图标与可访问性

  • 纯图标按钮必须加 aria-label（如 aria-label="写文章"），标签文字也可以同时放在旁边。
  • 图标统一 h-6 w-6，用 stroke="currentColor" 的单色 SVG，不要用 emoji。
  • 一个页面通常只保留一个 FAB；它是高频主操作的快捷入口，不要和主按钮、底部导航重复职责。
