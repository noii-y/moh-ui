字段分组 Fieldset

表单布局的骨架：用 fieldset 给一组相关控件加标题 legend、用 fieldset-label 放字段名或说明，还能整组禁用。下面先给一个设置页里可以直接拿走的通知分组，再列出各种排法供参考。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 改分组、标签、禁用只改 class 或加 disabled 即可；切换主题后，整组配色会自动跟着变。

单个字段：标题 + 输入框 + 说明

最基础的用法：fieldset-legend 当字段标题，下面跟输入控件，再用 fieldset-label 写一行辅助说明。比只放 placeholder 稳——输入后占位符会消失，标题和说明不会。

一组多个字段：label 与控件成对绑定

多个相关字段放进同一个 fieldset，legend 作整组标题；每个字段用 label 配 for、输入控件配同值 id，点文字就能聚焦到对应输入框，读屏软件也会正确朗读。

使用指南

fieldset 管分组，不代替控件本身

fieldset + legend 是语义容器，用来给一组相关输入加标题、统一布局和整组禁用；里面放的还是 input、select、checkbox 这些原生控件，各自有自己的样式类。

标题和标签要成对

整组标题用 fieldset-legend；单个字段名用 label 配 for、控件配 id。辅助说明用 fieldset-label，它会自动弱化成次要文字。不要把说明只写在 placeholder 里。

什么时候用整组禁用

权限或条件不满足时（未开通会员、认证已提交），整组加 disabled，并配一句说明原因；不要只把控件置灰却不告诉用户为什么。

可访问性

  • 屏幕阅读器会把 legend 读作这一组的标题，分组越清晰越好。
  • 点 label 要能聚焦到对应控件：务必让 for 与 id 一致。
  • 焦点描边不要去掉，键盘用户靠它判断当前在哪一个字段。

常见坑

  • 手机窄屏上，标题行右侧的下拉/开关别再用 ml-auto 硬推，容易被挤出屏；用 fieldset-legend 自带的两端对齐即可。
  • 不要为 fieldset 写死颜色或大段渐变，分组背景用 bg-base-200、边框用 border-base-300 这类主题色，深浅色都适配。
