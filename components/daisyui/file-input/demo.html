文件上传 File Input

选择本地文件的原生控件，用来上传头像、证件、附件。下面先给一个个人资料页可以直接拿走的上传区，再列出限定类型、多选、尺寸和状态供参考。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 改类型、尺寸、状态只改 class 即可；切换主题后，上传框颜色会自动跟着变。

个人资料页的上传头像区

字段标签在上、上传框占满整行，用 accept 只允许选图片，下面一行写清格式与大小限制，最后放「保存修改」主按钮；选中文件后的回显、上传进度属于业务逻辑，本成品不写 JS。

上传头像

支持 JPG / PNG，不超过 2MB

首选「复制 AI 提示词」整段发给你的 AI，它会按你的项目生成；想直接粘贴代码、双击预览，再用「复制成品 HTML」。

基础文件选择

最朴素的 file-input，点击后弹出系统文件选择框；默认不限类型。配 w-full 让它占满容器，max-w-md 限制最大宽度。

字段标签与格式说明

推荐用 fieldset + fieldset-legend 写清要传什么，fieldset-label 写规则（大小、格式、是否必填），比只放一个光秃秃的上传框清楚得多。

上传合同附件

支持 PDF、Word，单个不超过 10MB

限定文件类型

用 accept 过滤可选文件：accept="image/*" 只给图片，accept=".pdf,.doc,.docx" 限定扩展名。它只是缩小选择范围，真正的校验仍要在后端做。

多选文件

加 multiple 属性允许一次选多个文件，适合「上传多张凭证」「批量传附件」这类场景。

幽灵样式（无外框）

加 file-input-ghost 去掉描边，显得更轻，适合嵌在卡片、工具条里做次要上传入口。

尺寸四档

从 xs 到 lg 共四档（默认 md 最通用）；小尺寸塞进表格、评论区，大尺寸给移动端主上传区。

语义状态色

前两个分别是主色与成功色，最后一个是错误色：只有在「传错类型」「上传失败需重选」这类结果明确时才用，并且旁边要配文字说明，不要为了好看给上传框涂颜色。

禁用

条件不满足（如未开通、未到上传时间）时用 disabled 置灰，浏览器会同时禁止点击和聚焦。

使用指南

一定要写清传什么、有什么限制

用 fieldset-legend 说明用途，用 fieldset-label 写格式与大小限制；不要只放一个上传框让用户猜能传什么。

用 accept 缩小范围，但别只靠它

accept="image/*" 或扩展名列表能让文件选择框默认只显示对的类型，但用户仍能切到「所有文件」再选别的，最终格式与大小校验必须在后端和提交前再做一次。

多选与已选回显

multiple 允许一次选多个；已选文件列表、删除单个、上传进度都需要监听 change 事件的 JS 实现，属于业务逻辑，不在本组件纯 CSS 范围内。

状态色要配文字

file-input-error 红框只在校验失败时用，并写清「文件超过 2MB」「仅支持图片」等原因；不要默认给上传框涂醒目颜色。

常见坑

  • 不要用 Tailwind 任意值类（如 w-[300px]），用 w-full 加 max-w-md。
  • 禁用优先用 disabled 属性，它会同时阻止点击和聚焦。
  • 手机窄屏上上传框始终 w-full，不要写死固定宽度导致横向溢出。
