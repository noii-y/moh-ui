筛选条 Filter

把一组单选 / 多选做成一排按钮式筛选器，放在商品列表、文章列表顶部，让用户按条件过滤内容。选中后自动收起其余选项并露出重置按钮，窄屏自动换行。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 改分类、改多选项只改 aria-label 和 name；同一组单选必须共用一个 name。

单选分类：一次只选一个

用一个 <form class="filter"> 包住一组 type="radio"，同一组 radio 共用一个 name。末尾的 type="reset" 按钮平时隐藏，一旦选中某项就露出；点它可一键清空回「全部」。

多选标签：可叠加多个条件

把 input 换成 type="checkbox" 就是多选。与单选不同，选中某一项时其余选项不会收起，方便用户同时勾上多个标签；末尾的重置按钮会在任意一项勾选后出现。

不用表单：第一项即「全部」

不方便用 <form> 时，把外层换成 <div class="filter">，并给第一项加上 filter-reset。它本身就是「全部 / 不限」，选中它等于清除筛选，不需要额外的重置按钮。

使用指南

纯 CSS 只管「选中长什么样」，不管「真的过滤」

daisyUI 的 filter 用纯 CSS 实现了两件事：选中项高亮、选中后收起其余单选并露出重置按钮。但它本身不会去过滤下方的商品列表——真正按条件隐藏 / 显示列表项，需要你自己写一点 JavaScript（监听 change，按选中的 name 控制列表元素的显示）。别以为套上这个组件列表就会自动变。

单选与多选怎么选

  • 分类、状态这类「互斥」条件用 radio（如：数码家电 / 服饰鞋包）。
  • 标签、服务承诺这类「可叠加」条件用 checkbox（如：包邮 / 促销 / 新品）。
  • 同一组单选必须共用同一个 name，否则能同时选中多项。

为什么单选和多选的选中色不一样

注意两者的高亮方式：单选组选中某项后，其余选项会自动收起、只留下一个中性白底标签（这是 daisyUI 的收起机制，不是没生效）；多选组里选中的项则用主题色（主色）实心高亮。所以你看到单选是白底、多选是主色，不一样是正常的。

按钮文字与可访问性

radio / checkbox 套 btn 后，按钮上显示的文字来自 aria-label，不要漏写；重置的 × 按钮也建议补一个 aria-label="清除筛选"。

窄屏

.filter 自带 flex-wrap，选项多时会自动折行，不会把按钮挤出屏幕；手机上排不下就自然换成两行。
