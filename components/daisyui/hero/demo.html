三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 改标题、按钮、图片只改 class 和文案即可；切换主题后，整屏颜色会自动跟着变。

一段话讲清你是谁、能帮访客解决什么问题，下面只留一个按钮。

图文左右

落地页最常见的结构：左文右图（flex-col lg:flex-row），文字讲价值，图片给佐证。没有真实产品图时用渐变占位，接图时把 div 换成 <img>。

把复杂的事，讲简单

左边三五行讲清卖点，右边一张图或一段界面截图，比一大段文案更有说服力。

图文反向

把图换到左边：容器加 lg:flex-row-reverse，其余不变。一页里有好几段「图文」区块时，左右交替能打破单调。

数据自动汇总，不用手动做表

和上一段结构一样，只是图在左、文在右，页面节奏立刻不一样。

带登录表单卡

首屏右侧直接放一张登录卡（card w-full max-w-sm shadow-2xl），老用户不用再找「登录」入口。邮箱、密码用 fieldset 分组，「忘记密码」是链接不是按钮，登录动作整宽按钮收尾。

登录你的工作台

右侧直接登录，老用户进来就能开工；新用户往下滚动看注册入口。

内联渐变背景

彩色或图片背景上叠一层 hero-overlay 压暗，文字换 text-neutral-content 保证对比度。这里用内联渐变占位，真实项目把它换成你的品牌图或视频。

深色渐变上的首屏

背景越深，文字越要够亮够粗；按钮用实心主色，在暗背景上依然跳得出来。

使用指南

一屏只讲一件事、只给一个主按钮

首屏的任务是「让人知道你是干嘛的 + 点哪里继续」：大标题一句话讲清价值，下面最多两个按钮（一个实心主操作 + 一个弱化的次要操作），星级、客户 logo 这类信任元素挤在同一行就够了，不要再加导航、再加报名表单。

标题别被挤成单字断行

左右两列都加 min-w-0，右列产品图卡用 shrink-0 固定不缩；标题在合理位置主动断行（<br />），字号桌面 lg:text-4xl 或 lg:text-5xl、手机降到 text-2xl 或 text-3xl。宁可主动断行，也不要被挤成「项目管理工／具」这种单字孤行。

别写死整屏高度

本库示例一律用 py-20 或 py-24 控制留白，不写 min-h-screen——在文档流或卡片里它会把页面撑满、盖住复制按钮。真要做整屏高度的独立落地页时，再给 hero 加 min-h-screen。

图与背景用占位、教用户换真图

产品图、背景一律用内联 linear-gradient 或内联 SVG 占位，不外链图片；教程里明确告诉用户「换成你的真实截图」。背景视频、自动轮播这类效果需要 JS，不在纯 CSS 范围内。

深色背景上的对比度

叠了 hero-overlay 或用深色渐变时，文字必须用 text-neutral-content（或白），按钮用实心 btn-primary；不要在暗背景上放半透明幽灵按钮，会看不清。
