文本输入框 Input

单行文本输入，用来收集邮箱、密码、搜索关键词等内容。下面先给一个登录表单的输入区成品，再列出各种类型、图标、尺寸和状态供参考。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 改类型、尺寸、状态只改 class 即可；切换主题后，输入框颜色会自动跟着变。

单行输入的各种类型

同一个 input 类适用于 text、email、password、number、date、time、tel、url、search 等所有单行类型，改 type 即可拿到对应的键盘和校验行为。

内嵌图标、快捷键与徽标

把 input 类放在外层 label 上，内部放图标、快捷键或徽标；真正的输入框加 grow 自动撑满剩余宽度。图标用 h-4 加 opacity-50 弱化。

幽灵输入框（无外框）

加 input-ghost 去掉描边，只保留下划线感，适合嵌在工具条、卡片里做轻量筛选，不抢视觉。

字段标签 fieldset

推荐用 fieldset + fieldset-legend 组织「标签 + 输入框 + 提示」，比单独放 placeholder 更稳——输入后占位符会消失，标签不会。

尺寸五档

从 xs 到 xl 共五档，默认 md 最通用；小尺寸塞进表格内联编辑和筛选条，大尺寸给移动端主表单。

禁用

条件不满足时用 disabled 属性置灰，浏览器会同时禁止聚焦和输入；只读不改的内容用 readonly（样式不同）。

输入建议 datalist

给 input 加 list 指向一个原生 <datalist>，输入时自动给出候选，零 JS。

原生校验 validator

外层 label 加 validator，配合原生 required / pattern / minlength：失焦或提交时自动显示成功绿或错误红，旁边的 validator-hint 写清规则，无需任何脚本。

使用指南

每个输入框都要有可见标签

优先用 fieldset + fieldset-legend，或成对的 <label for="id">；不要只放 placeholder——用户一打字占位符就消失了，回头不知道自己在填什么。

类型要写对

  • 邮箱用 type="email"、密码用 type="password"、数字用 type="number"：手机键盘会自动切换，浏览器也会自带基础校验。
  • 登录类表单顺手加上 autocomplete（如 email / current-password），密码管理器才能自动填充。

状态色必须配文字

input-error 红框、input-warning 橙框只在校验结果明确时用，并且旁边或占位处要说清楚错在哪、该怎么改——只变红用户不知道怎么改。

内嵌写法

图标 / 快捷键 / 徽标都放在外层 <label class="input"> 里，真正的输入框加 grow；图标统一 h-4 加 opacity-50，别和输入内容抢注意力。

常见坑

  • 不要用 Tailwind 任意值类（如 h-[1em]），补丁层不支持，一律换成标准类。
  • 禁用优先用 disabled 属性；需要只读不置灰时才用 readonly。
  • 键盘焦点自带高亮描边，不要为了"好看"把它去掉。
