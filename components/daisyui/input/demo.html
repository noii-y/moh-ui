文本输入框 Input

单行文本输入。示例结构搬运自 daisyUI 官方文档，已做零依赖改造。

来源：daisyui.com/components/input（MIT）

基础

适用于 text、password、email、number、date、tel、url、search 等任意单行类型。

内嵌图标 / 文字

把 input 类放在外层 label 上，内部可放图标、快捷键、徽标，真正的 input 加 grow 撑满。

幽灵样式

input-ghost：无外框，嵌入卡片、工具栏时使用。

字段标签（fieldset）

官方推荐用 fieldset + fieldset-legend 组织"标题 + 输入框 + 提示"。

颜色

语义色边框，通常用于状态提示（错误、警告、成功）。

尺寸

input-xs / input-sm / 默认 md / input-lg / input-xl。

禁用

带输入建议（datalist）

原生 datalist，输入时给出候选，无需 JS。

带校验（validator）

配合原生 required / pattern / minlength，失焦后自动显示成功或错误色，详见"校验"组件。

3 到 30 个字符，只能含字母、数字或连字符
