组合容器 Join

把输入框、下拉框、按钮无缝拼成一条——首尾自动圆角、相邻之间没有间隙。最常见的就是「分类下拉 + 搜索框 + 搜索按钮」这种连体工具栏。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 每个拼进去的元素都加 join-item，首尾圆角由 join 自动处理；中间项想占满剩余宽度就加 min-w-0 flex-1。
成品示例 · 拿来即用

电商搜索框：类别下拉 + 输入框 + 搜索按钮

左边一个定宽的类别下拉，中间搜索框占满剩余宽度并能随容器收缩，右边一个带放大镜图标的主按钮。三者边缘自动衔接成一整条，没有拼缝。

首选「复制 AI 提示词」整段发给你的 AI，它会按你的项目生成；想直接粘贴代码、双击预览，再用「复制成品 HTML」。

邮箱订阅：输入框 + 按钮

最常见的组合：一个邮箱输入框接一个订阅按钮。输入框加 min-w-0 flex-1 占满剩余宽度，首尾圆角由 join 自动处理。

分段按钮组：日 / 周 / 月

一排等宽按钮无缝连成一组，用 btn-active 标出当前选中的一档，适合「日 / 周 / 月」「最新 / 最热」这类切换。

竖排：上下叠进一张卡片

加 join-vertical 改成纵向拼接，适合塞进卡片或侧栏里，把一组输入和提交按钮上下连成一片。

响应式：手机竖排、桌面横排

同时加 join-vertical lg:join-horizontal：窄屏时上下堆叠不占横向宽度，到大屏（lg）自动变回横向一排。

使用指南

每个拼进去的元素都要加 join-item

不管是 input、select、button 还是 textarea，加了 join-item 才会自动去掉相邻间隙、只在整组首尾保留圆角。

中间的输入框要能收缩

横排里中间的 input 同时加 min-w-0 flex-1：flex-1 让它占满剩余宽度，min-w-0 允许它在窄屏收缩而不是把整组撑出屏幕。左侧下拉用定宽（如 w-32），右侧按钮用自然宽度。

方向与响应式

  • 默认横向拼接；纵向加 join-vertical。
  • 手机想竖排、桌面想横排：join join-vertical lg:join-horizontal。

分段切换的选中态

按钮组里用 btn-active 表示当前档；若要随点击真实切换，再用一小段 JS 或 radio 实现，join 本身只负责外观拼接。
