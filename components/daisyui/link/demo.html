链接 Link

网页里指向另一个页面或位置的跳转。daisyUI 的 link 把被 Tailwind 重置掉的下划线加回来，并提供一套语义色。下面先给一个登录 / 注册卡片底部的链接区成品，再列出颜色、下划线等写法供参考。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 改颜色、下划线只改 class 即可；切换主题后，链接颜色会自动跟着变。

基础链接：带下划线

加 link 把下划线加回来，最适合正文段落里嵌的链接——用户能一眼认出「这是可以点的」。

在 link 后面接语义色，链接文字仍写真实动作。主色用于最想引导的跳转，错误 / 警告只在含义明确时用。

只有 hover 才显示下划线

加 link-hover：平时是一行干净的彩色文字，鼠标移上去才出现下划线。适合导航、辅助操作这类不想让下划线打断排版的地方。

无下划线的彩色链接

只加颜色类（如 link-primary）、不加 link，就得到「有颜色、没下划线」的链接。这也是正文里最常见的写法：靠颜色区分，不靠下划线。

使用指南

链接还是按钮

跳转、看详情、到另一个页面用 <a class="link">；提交、保存、删除、弹出框这类动作依旧用 <button>。不要用链接去假装执行动作，也不要用按钮去做页面跳转。

下划线要不要画

  • link：带下划线，正文段落里最稳，一眼能点。
  • link link-hover：平时干净、hover 才出下划线，适合导航与辅助操作。
  • 只写 link-primary 不写 link：纯彩色无下划线，适合已经很明确的跳转语境。

颜色是有含义的

主色只留给最想引导用户走的那一个跳转；link-error、link-warning 只有在「被驳回」「即将到期」这类含义明确时才用，不要为了好看把链接染成红色。

外链与安全

新窗口打开外链必须成对写 target="_blank" 与 rel="noopener"，否则新页面能通过 window.opener 反向操作你的页面。站内跳转不要随意开新窗口。

可访问性

链接要有足够的颜色对比（正文 ≥ 4.5:1）；不要只靠颜色区分可点与不可点，正文里的链接保留下划线或 hover 反馈；键盘 Tab 焦点描边不要去掉。
