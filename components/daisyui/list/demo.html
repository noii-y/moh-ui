列表 List

纵向排列的条目容器：地址簿、播放列表、设置项都用它。下面先给一个收货地址选择的成品，再列出图标列表等形态。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 加图标、改间距只改 class 即可；切换主题后，列表颜色会自动跟着变。

紧凑条目列表

没有卡片底色、没有阴影，直接用 <ul class="list"> 放在页面背景上；中间信息块用 list-col-grow 强制撑开，末尾放小按钮。适合「最近浏览」「播放队列」这类密度优先的场景。

使用指南

list-row 的网格规律

list-row 内部是一个网格：默认第二个子元素自动填满剩余宽度。所以标准写法是「小图标 + 信息块 + 末尾按钮」；想让别的块撑开，给它加 list-col-grow；想让一段长文字换到下一行，给它加 list-col-wrap。

语义化

列表用 <ul> / <li>，不要用 <div> 硬拼；单行里的单选（如收货地址）用 <input type="radio"> 并加 aria-label，保证键盘和读屏可用。

操作按钮

每行末尾的操作统一用 btn btn-xs btn-ghost；删除这类危险动作加 text-error 提示，但不要用实心红按钮吓人。

卡片外壳

需要从页面背景里浮出来时，外层加 bg-base-100 rounded-box shadow-md；嵌进白色页面容器里时直接裸用 list 即可，不要到处套卡片。
