代码窗口样机 Mockup Code

画一个深色代码编辑器窗口，带行号或符号前缀，用来在文档里展示一段代码。下面先给一个可以直接拿走的成品。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 每一行代码是一个 <pre data-prefix="行号">，把里面的 <code> 换成你的代码即可（尖括号记得转义）。
成品示例 · 拿来即用

展示一段按钮组件代码

深色代码窗口，左侧行号 1–5，内容是一段真实的按钮组件 HTML（带中文注释），用来在教程或文档里说明「这段代码长这样」。

<!-- 主按钮 -->
<button class="btn btn-primary">
  保存修改
</button>

不带任何前缀

省略 data-prefix，就是一段干净的代码块，适合直接贴一段片段。

/* 主按钮色跟随主题 */
.btn-primary {
  background: var(--color-primary);
}

使用指南

一行一个 pre

每一行代码单独写一个 <pre data-prefix="...">，daisyUI 会自动把前缀放在左侧行号槽里；不要把多行塞进一个 pre。

代码要转义

在 <code> 里写 HTML 代码时，尖括号必须写成 &lt; 和 &gt;，否则浏览器会把它当成真元素渲染出来，而不是显示成文本。

什么时候用高亮

只高亮一行：关键配置、报错信息或新增代码。用 bg-warning 标警告、text-success 标成功，不要每行都上色。

它是展示样机

mockup-code 只用来展示代码样子，不带复制按钮、不带语法高亮配色；需要真高亮和复制功能时用代码高亮库。
