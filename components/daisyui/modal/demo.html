对话框 Modal

必须用户做决定时才弹出的居中浮层：删除确认、填写必要信息。它带一层遮罩，不处理就不能继续。下面先给一个删除确认成品，再看关闭按钮、底部抽屉和自定义宽度。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 真实项目推荐 <dialog class="modal"> 加一行 showModal()（支持 Esc 关闭、锁定背景）；本页为静态展示用复选框法，指南里有说明。
成品示例 · 拿来即用

删除收货地址的确认对话框

删除是不可恢复的操作，必须弹层让用户再确认一次：标题直接问要做什么，正文说清后果，底部「取消」退回、「确认删除」用红色提示风险。本页为了在小舞台里展示，给弹层加了内联 position:static（真实项目删掉就自动铺满全屏）。

确认删除这条收货地址？

此操作不可撤销，删除后该地址将无法找回。

首选「复制 AI 提示词」整段发给你的 AI，它会按你的项目生成；想直接粘贴代码、双击预览，再用「复制成品 HTML」。

右上角关闭按钮

信息类弹窗右上角放一个圆形幽灵 ✕，让用户随时能关掉。这里是静态展示：真实项目里 ✕ 关闭的行为由 showModal() 方案的 <form method="dialog"> 提供，无需自己写 JS。

导出报表

报表将发送到你的注册邮箱，约 1 分钟后可查收。

底部抽屉（手机端常用）

加 modal-bottom，弹窗从屏幕底部升起、顶部两个角是圆角，手机端选地址、选规格都用这种形态，手指够得着。本页给舞台加了固定高度来演示它贴底的样子。

选择配送方式

可以选快递送货上门，也可以到附近自提点自取。

自定义宽度

默认弹窗宽度 max-width:32rem；描述文字多的场景（长表单说明、协议摘要）把 modal-box 加宽到 max-width:42rem 左右，别一上来铺满整屏。

编辑活动规则

这里放一段较长的说明文字：活动时间、参与门槛、奖品发放规则都写在这个弹窗里。宽弹窗适合描述文字多的场景，窄弹窗只放一句话加两个按钮。

纯信息提示（不涉及危险）

不需要做不可逆决定时，主操作用主色按钮、次要操作弱化成幽灵按钮；只有删除、清空这类危险确认才用红色。

使用指南

真实项目推荐：dialog + showModal()

daisyUI 官方首推 HTML 原生 <dialog>：打开只需 document.getElementById('弹窗id').showModal()，按 Esc 关闭、自动锁定背景交互、焦点圈定都由浏览器原生提供。骨架如下：

<button class="btn" onclick="地址删除确认.showModal()">删除</button>
<dialog id="地址删除确认" class="modal"> → 里面放 div.modal-box 与 div.modal-action；关闭按钮包一层 <form method="dialog">，点它自动关闭，无需 JS。

本页为什么用复选框法

详情页要静态展示弹窗长什么样，又不写 JavaScript，所以用隐藏复选框（modal-toggle 勾选状态）把弹窗撑开展示。它属于官方 Method 3（legacy）：不支持 Esc、不锁背景，只适合无 JS 环境或纯展示。每个弹窗的 id 必须唯一。

关于本页的内联样式

详情页给 .modal 加了 position:static;pointer-events:none，只为在小舞台里排开展示、不盖住页面；复制进真实项目后删掉这行内联样式，弹窗会自动 fixed 铺满全屏并带半透明遮罩。

按钮与文案

modal-action 里按钮自动右对齐；危险确认（删除、清空）主按钮用 btn-error，普通确认用 btn-primary，退回用默认或幽灵按钮。标题写真实决策问题，正文说清后果，不写"确定要执行该操作吗"这种官话。
