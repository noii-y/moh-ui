进度条 Progress

告诉用户「事情走到哪一步了」：上传文件、保存导出、任务排队都用它。下面先给一个文件上传成品，再看语义色、不确定进度和完成态。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 进度写在 value 和 max 属性里，颜色加 progress-primary 等语义类，切换主题后自动跟随。

语义色

进度条颜色就是状态色：主色表示正在进行，次色表示次要任务，绿 / 橙 / 红只在含义明确时用。颜色走主题变量，不写死色值。

不确定进度（不知道走到哪）

拿不到真实百分比时（比如等待队列、首次加载），不要硬填一个假数字——去掉 value 属性，浏览器会自己跑一段来回移动的动画，表示「在走，但不知道走多远」。

进度条加数值标签

长任务一定要把数字写出来，用户才知道还要等多久：条上方一行左名字右百分比，数字和 value 保持一致。

完成态

走到 100% 换成功色，旁边把文案从「上传中」改成结果（上传完成 / 已保存），别让条停在 99% 一直转圈。

细线小号

顶栏下载、后台任务这类不打扰的位置，把条压细一点（高度用内联 style 调到 6px），视觉重量立刻降下来。

使用指南

知道多少填多少，不知道就留空

有真实进度（上传、下载）就填 value="45" max="100"；拿不到进度就去掉 value 属性用不确定动画，不要伪造一个慢慢涨的假数字骗用户。

数字要和条对上

显示「72%」时 value 就必须是 72；进度条更新时百分比文案同步更新，对不上比没有数字更糟糕。

颜色语义

  • progress-primary：主任务正在进行。
  • progress-secondary / accent：次要任务。
  • progress-success：100% 完成态。
  • progress-warning / progress-error：预计超时、失败兜底。

可访问性

进度条用原生 <progress> 标签，读屏天然认识它；纯展示用 div 时补 role="progressbar"、aria-valuenow、aria-valuemin/max。不确定进度不要写 aria-valuenow。
