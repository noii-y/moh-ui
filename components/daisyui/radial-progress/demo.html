环形进度 Radial Progress

用一个圆环表示完成度：目标达成率、任务进度、倒计时都适合。下面先给一个可以直接拿走的数据看板成品。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 进度值、大小、环厚都写在 style 里的三个 CSS 变量上，不改类。

使用指南

三个 CSS 变量是本体

radial-progress 靠 --value（0–100）显示进度，--size 控直径，--thickness 控环厚；改数字只动 style，不加新类。

用 div，别用 progress 标签

官方说明：环内要显示文字，且部分浏览器不渲染 progress 标签里的伪元素，所以一律用 div + role="progressbar" + aria-valuenow。

颜色就是文字色

环条颜色取元素的文字颜色：text-primary / text-success 等，不要写死色值。

什么时候用它

单个百分比、一眼能看完的完成度用环；多指标横向比较请用横条进度，环不要并列超过四个。
