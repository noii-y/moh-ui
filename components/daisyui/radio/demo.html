单选框 Radio

从一组互斥选项里选一个，同一组必须用相同的 name。下面先给一个结算页可以直接拿走的付款方式选择区，再列出各种尺寸、颜色和状态供参考。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 改颜色、尺寸只改 class 即可；切换主题后，整套单选框颜色会自动跟着变。

付款方式
首选「复制 AI 提示词」整段发给你的 AI，它会按你的项目生成；想直接粘贴代码、双击预览，再用「复制成品 HTML」。

基础单选态

最朴素的形态：同一组用相同的 name，选了其中一个，其它自动取消；默认想选中哪项就加 checked。

点文字也能选

用 label 把单选框和文字包在一起，整行都可点，比只有小圆点好操作得多；这也是把选项排成带说明清单的常用写法。

分组：fieldset 加 legend

一组互斥选项放进 fieldset 并写 legend，屏幕阅读器会把它读作这一组的标题，比光秃秃一排小圆点更清楚。

发票类型

尺寸

共五档，默认大小最通用；小尺寸适合紧凑表格行，大尺寸适合移动端选择页。

语义状态色

这一排是 daisyUI 的语义状态色：从主色到错误色，分别对应主操作、强调、成功、警告、错误等含义。实际使用时按需取用，不要为了好看全用醒目颜色。

禁用

条件不满足时禁用某个选项；禁用且选中表示「这项已由系统设定好、当前不可改」。用 disabled 属性。

使用指南

单选框还是复选框

互斥、只能选一个（付款方式、配送方式、性别）用单选框 Radio；可同时多选、互相独立（通知渠道、协议勾选）用复选框 Checkbox。

同一组必须同名 name

互斥是靠 name 相同实现的：一组单选框全部写成同一个 name（如 name="pay"），选一个就会自动取消其它；不同组之间 name 要不同。

一定让文字可点

每一项都用 label.label.cursor-pointer 包住 input 和文字，点击区域从小圆点扩大到整行，手机上尤其重要。

分组用 fieldset

一组相关选项用 fieldset.fieldset 加 legend 包起来，读屏软件会自动把 legend 读作组标题。

可访问性与禁用

键盘 Tab 聚焦后用方向键在同组选项间切换，焦点描边不要去掉；禁用优先用 disabled 属性，它会同时阻止点击和聚焦。
