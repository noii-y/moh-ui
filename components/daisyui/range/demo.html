滑块 Range

通过拖动滑杆在一个连续区间里选数值，如价格上限、音量、透明度。下面先给一个筛选栏可以直接拿走的预算滑块，再列出带刻度、尺寸、颜色和竖向等形态供参考。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 改颜色、尺寸只改 class 或 min / max / step 即可；切换主题后，整套滑块颜色会自动跟着变。

竖向

加 range-vertical 并给一个固定高度（h-40），适合混音器、亮度面板这类竖排布局。

使用指南

什么时候用滑块

连续、近似的数值调节（价格区间、音量、亮度、透明度）用滑块；如果选项离散且需要精确列举（配送方式、付款方式），改用单选框或下拉。

一定标清区间和当前值

用 min / max 写明两端范围，最好在旁边实时显示当前值；纯 CSS 无法回显拖动中的数值，本成品用一行极小 JS 监听 input 事件更新金额——除此之外不要写别的交互。

步长符合业务

用 step 限制可选档位（价格每次 100 元、评分每次 0.5 分），避免用户拖出无意义的中间值。

可访问性

原生滑块支持键盘方向键微调，焦点描边不要去掉；不要用自定义 div 拖块替换原生 input type="range"，那会丢掉键盘和读屏支持。
