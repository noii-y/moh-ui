下拉选择 Select

从一组固定选项里选一个值，比手敲更稳、不易出错。下面先给一个收货地址选择区的成品，再列出幽灵、字段标签、尺寸和状态色等形态供参考。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 改颜色、尺寸只改 class 即可；切换主题后，整套下拉颜色会自动跟着变。

首选「复制 AI 提示词」整段发给你的 AI，它会按你的项目生成；想直接粘贴代码、双击预览，再用「复制成品 HTML」。

基础下拉与占位项

第一项设为 disabled selected 当作占位提示，用户必须主动选一个，避免把默认项误当成已选。选项写真实业务内容。

幽灵下拉（无外框）

加 select-ghost 去掉描边，弱化成一行文字，适合嵌在工具条、表格工具栏里做轻量切换，不抢视觉。

字段标签 fieldset

推荐用 fieldset + fieldset-legend 组织「标签 + 下拉 + 说明」，比只靠占位项更稳——选定后用户仍看得到这一栏在问什么。

发票抬头 选企业抬头需另外填写税号

语义状态色边框

前三个是强调边框，标出当前重点；后面是语义状态色，只有在含义明确时才用，而且要像下面这样把结果写成人话，不能只是框变色。

尺寸五档

共五档，默认大小最通用；小尺寸适合表格筛选条，大尺寸适合移动端主表单。

禁用

条件不满足或权限不足时用 disabled 置灰；禁用的下拉用户既点不开也看不出被藏了什么，所以里面要放一个说人话的当前值。

使用指南

什么时候用下拉，什么时候用单选

选项很多（省市区、城市、商品类目）或一行塞不下时用下拉；选项只有两三个（性别、付款方式）时直接用单选按钮铺开，别让用户多点一次。

放一个占位项

需要「必选」时，第一项用 <option disabled selected>请选择…</option>，不要给一个看似默认、实则没意义的真实选项。

每个下拉都要有标签

优先用 fieldset + fieldset-legend，或成对的 <label for="id">；只靠占位项的话，一旦选定，用户就看不到这一栏在问什么了。

状态色必须配文字

select-error、select-warning 这类只在含义明确时用，并且占位项要说清楚为什么是这个状态（如「该地区暂不支持配送」），不能只把框变红。

可访问性

原生下拉自带键盘操作（上下键选择、回车确认），焦点高亮描边不要去掉；禁用优先用 disabled 属性，它会同时阻止展开和聚焦。
