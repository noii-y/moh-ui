叠放 Stack

把几张卡片或图片叠成一摞：图册、通知堆、头像组都适用。下面先给一个可以直接拿走的产品图册成品。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 把要叠的卡片放进 stack 容器，第一个子元素在最上层。

使用指南

第一个子元素在最上层

stack 把所有子元素放进同一格子重叠：第一张卡在最上层（z-index 最高），后面的卡片依次压在下层并略微透明。想让哪张卡在最前面，就把它放第一个。

hover 展开怎么做

本库工具类补丁未提供 hover: 前缀类，静态演示里用最小内联 transform 把后面的卡片错开；真实项目里的 hover 展开，请用内联 hover CSS 或你项目里的 Tailwind hover 类（如 hover:-translate-x-4），不要为本库写 JS。

限宽防溢出

整个叠摞用 w-* / max-w-full 限宽，手机窄屏不会横向溢出。
