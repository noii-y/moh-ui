切换状态 Swap

同一个位置上的两种图标状态：收藏与已收藏、静音与有声、白天与黑夜、显示与隐藏密码。点一下纯 CSS 切换，不需要任何 JavaScript。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 结构是一个 label.swap 包住一个隐藏的 checkbox 和 swap-off / swap-on 两副图标；要默认显示「on」就给 input 加 checked。

旋转切换：添加与完成

加 swap-rotate，切换时图标转 45°。适合「添加 / 完成」这类动作翻转，比如清单上勾掉一项。

翻转切换：显示与隐藏密码

加 swap-flip，切换时图标沿垂直轴翻面。适合输入框右侧的「显示密码 / 隐藏密码」。

昼夜模式

太阳与月亮互切，是后台「浅色 / 深色模式」开关的常见做法。当前是浅色就显示太阳（点它切深色），勾选状态即「深色模式已开」。

音量与静音

播放器、会议里的「静音 / 取消静音」：喇叭与划掉的喇叭互切。

使用指南

结构就是 label + checkbox + 两副图标

外层 label.swap 里依次放：一个隐藏的 input[type=checkbox]、div.swap-off（默认态图标）、div.swap-on（选中态图标）。两副图标叠在同一格，靠 checkbox 的 :checked 切透明度，因此全程纯 CSS、零 JS。

默认显示哪一态

默认显示「未选中」（swap-off）。要让按钮打开就是选中态，给 input 加 checked 属性；静态页面想强制展示 on 态而不依赖 input，也可以直接在 label 上加 swap-active 类。

动画选哪种

swap-rotate 旋转 45°（收藏、添加、静音这类「按一下翻转」），swap-flip 沿垂直轴翻面（显示 / 隐藏密码）；不加修饰类就是直接淡入淡出。

可访问性

checkbox 是隐藏的（appearance:none），必须给它加 aria-label 说明这个开关干什么（如「收藏商品」「切换静音」），否则读屏用户只听到一个无名复选框。label 包住 input，点图标任何位置都能切换，键盘 Tab + 空格同样可用。

颜色别写死

「已收藏」的星变黄、「静音」的喇叭变红，用 text-warning / text-error 等语义色，不要写死色值，换主题时自动跟随。
