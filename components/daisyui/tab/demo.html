标签页 Tab

把同一层级的几类内容收进一排标签，点哪个就显示哪块，不用翻页。下面先给一个订单中心的成品，再列出下划线、提升、盒装等形态供参考。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 换形态只改容器 class（tabs-border / tabs-lift / tabs-box）即可；切换主题后，整套标签颜色会自动跟着变。

使用指南

标签页不是表单单选

标签页用来切换可见的内容区块（订单状态、商品详情页的几个区块）；表单里「选一个付款方式」那类才是单选框 Radio。两者都用同名 name，别混用。

纯 CSS 切换：radio 加紧跟的内容块

零 JS 写法是一组同名 <input type="radio" class="tab">，每选一个，它后面紧跟的那块 .tab-content 才显示。想默认打开哪一类，就给那个 radio 加 checked，它的内容会自动露出来——截图前务必确认当前项的内容是可见的。

每组标签 name 唯一

同一个页面里有多组标签时，每组 radio 的 name 必须不同（如 order_status、panel_tab），否则会互相串台、一起取消选中。

标签太多：折行还是横滑

带 tab-content 的 radio 标签（如本页成品）要靠标签自动换行，把内容块挤到标签行下方，所以窄屏放不下时让它自然折成两行、别强行 flex-nowrap；只有纯标签、不带内容块的链接式标签（如下划线、提升、盒装那几个），才适合在窄屏外层包 overflow-x-auto、每项加 shrink-0 做成单行横向滑动。无论哪种，都不能把整页撑出横向滚动条。

可访问性

用 <a> 做标签时加 role="tab"；用 radio 做标签时用 aria-label 写出中文标签名，读屏软件才能念出来。键盘方向键可在 radio 组间切换，焦点描边不要去掉。
