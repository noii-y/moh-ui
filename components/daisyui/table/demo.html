表格 Table

用行列结构展示一批同构数据：订单、用户、库存都适合表格。下面先给一个后台订单管理的成品，再列出斑马纹、悬停、粘性表头/首列等形态。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 加斑马纹、粘性表头只改 class 即可；切换主题后，表格颜色会自动跟着变。

使用指南

永远先包 overflow-x-auto

表格列多时一定会在窄屏溢出。正确做法是表外套 <div class="overflow-x-auto">：表内横向滑动，页面本身不出现横向滚动条。不要为了塞下所有列去缩小字号。

粘性表头 / 首列

table-pin-rows（表头吸顶）和 table-pin-cols（首列吸左）都要求外层有独立滚动容器：纵向滚动用 height + overflow-y-auto，横向滚动用 overflow-x-auto。没有定高容器时加 pin 类不会有任何效果。

状态用徽章，别用文字颜色

订单状态、审批状态这类枚举值用 badge badge-sm + 语义色（success / warning / info / error），不要只靠红绿字体——色盲和打印环境都会丢信息。

操作列

操作按钮放最后一列，用 btn btn-xs btn-ghost 弱化次要动作，当前状态对应的主动作（如「发货」）才用 btn-primary；没有该状态的动作就不渲染，别放一个禁用按钮占位。

数字对齐

金额、数量这类数字列建议右对齐（text-right）并使用等宽数字，方便逐位比较；表格默认左对齐，只对数字列单独加。
