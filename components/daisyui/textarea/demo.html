多行文本域 Textarea

让用户输入多行文本，适合备注、意见反馈、个人简介这类内容较长的场景。下面先给一个意见反馈输入区的成品，再列出固定高度、幽灵、尺寸和状态色等形态供参考。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 改高度、尺寸、状态只改 class 即可；切换主题后，文本域颜色会自动跟着变。

基础多行输入

最朴素的写法，给 textarea 加 w-full 占满宽度。placeholder 写引导性内容，不要把字段名塞进去。

固定高度

默认高度偏矮，看不出是多行输入。用 h-24、h-32 这类标准高度类给足输入空间；浏览器仍可拖拽右下角调大小。

幽灵文本域（无外框）

加 textarea-ghost 去掉描边，只保留下划线感，适合嵌在卡片、评论流里做轻量输入，不抢视觉。

字段标签 fieldset

推荐用 fieldset + fieldset-legend 组织「标签 + 文本域 + 字数说明」，比只放 placeholder 更稳——一打字占位符就没了，标签不会。

尺寸五档

从 xs 到 xl 共五档，默认大小最通用；小尺寸适合评论回复框，大尺寸适合发帖、写正文。

禁用

条件不满足时用 disabled 置灰；已经锁定、不可再改的内容也用它，旁边说明原因。

使用指南

单行还是多行

一两个词、一行能写完（姓名、邮箱、地址）用单行 input；一段话、可能换行（备注、反馈、简介）用 textarea。

给足高度

默认高度偏矮，加 h-24 / h-32 让用户一眼知道能写多行；别让它看起来像个单行输入框。

字数上限配实时计数

有 maxlength 时，在 fieldset-label 旁放一行「已填 X/N 字」，用一小段 JS 监听 input 事件更新数字（本页成品即此写法）；不要只限制不提示，用户打到上限被截断会莫名其妙。

每个文本域都要有标签

优先用 fieldset + fieldset-legend，或成对的 <label for="id">；不要只靠 placeholder——一打字占位符就消失。

状态色必须配文字

textarea-error、textarea-warning 只在校验结果明确时用，并且要说清楚错在哪、怎么改；禁用优先用 disabled 属性。
