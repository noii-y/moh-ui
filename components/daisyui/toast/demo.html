通知浮层 Toast

操作完成后自动弹在屏幕角落的小通知：保存成功、收到新消息。它几秒后自己消失，不打断用户正在做的事。下面先给一个右下角堆叠成品，再看九个位置和带按钮的写法。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 换位置只改外层 toast-* 类组合；多条通知往 toast 里继续加 alert 即可，自动纵向堆叠。
成品示例 · 拿来即用

操作后右下角的通知堆叠

九个弹出位置

外层 toast 组合两类类名：垂直位置 toast-top / toast-middle / toast-bottom（默认底部），水平对齐 toast-start / toast-center / toast-end（默认居右）。桌面端最常用右下角，手机端通常顶部居中，避免被手势遮挡。

使用指南

关于本页的 position:static

toast 本体是 position:fixed，真实项目里挂在 <body> 末尾、自动贴在屏幕角落；本详情页把它放进小舞台，只能临时加内联 style="position:static" 才能铺开展示。复制到真实项目后删掉这行内联样式，它会自动回到 fixed 定位。

真实交互怎么接

Toast 不是写死在页面上的，而是由 JavaScript 动态创建：操作成功后往 .toast 里插一条 alert，停留 3~5 秒后再移除。纯静态写死一条通知在页面里，等于一条不会消失的提示条，那就直接用 Alert 组件。

位置怎么选

桌面端默认底部居右即可；手机端建议顶部居中（toast-top toast-center），避开底部手势区。整页通知位置全站统一，别一个模块一个角落。

密度与文案

一次最多堆两三条通知，成串弹出等于没有通知。文案写真实事件（保存成功、收到 3 条新消息、订单已发货），别写"操作成功"这种空话；错误类通知停留久一点，成功类快闪即可。
