悬浮提示 Tooltip

鼠标停在图标按钮上、或键盘把焦点移到按钮上时冒出来的一句小字，用来解释它是什么、快捷键是多少。它不拦截焦点、不是弹层。下面先给一个编辑器工具栏的成品，再列出四个方向、语义色和真实可点的形态供参考。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 提示文字写在 data-tip 属性里；换方向、换颜色只改 class。
成品示例 · 拿来即用

编辑器工具栏的图标按钮

纯图标按钮看不清用途，停上去给出一句话说明和快捷键「保存 (Ctrl+S)」。外层一个 tooltip 包住按钮，文字放在 data-tip 里；为在页面里静态展示，临时加了 tooltip-open 并给舞台留出上方空间。

首选「复制 AI 提示词」整段发给你的 AI，它会按你的项目生成；想直接粘贴代码、双击预览，再用「复制成品 HTML」。

四个弹出方向

默认从上方弹出；按钮靠近上边缘时用 tooltip-bottom，靠近屏幕两侧时用 tooltip-left / tooltip-right，避免气泡被裁切。

语义色提示

默认是中性灰。主色 / 次色 / 错误色只在含义明确时使用：主色提示推荐操作，红色提示该动作有风险。

带图标的提示

用 tooltip-content 代替 data-tip，气泡里可以放任意内容，比如一个小图标加一句说明。

真实可点：键盘 Tab 到按钮上试试

上面的气泡是用 tooltip-open 强制展示的。真实用法里它们平时不出现：鼠标悬停在按钮上、或用键盘 Tab 把焦点移到按钮上，气泡才弹出（daisyUI 靠 :has(:focus-visible) 识别键盘聚焦）；鼠标移开、或 Tab 走到下一个元素，气泡立刻消失。它不是弹层：不拦截焦点、不用 Tab 圈定、按 Esc 也与它无关，焦点始终停在按钮本身。静态截图里只看到一排按钮，正是收起状态。

使用指南

一句话，别超过两行

提示只写「这是什么 + 快捷键 / 结果」，例如「保存 (Ctrl+S)」「删除后不可恢复」；不要放长段落、不要放链接（需要跳转就用下拉或弹窗）。

纯图标按钮必须有提示

工具栏上只有图标、没有文字的按钮，data-tip 就是它给视力用户的说明；按钮本身还要加 aria-label，照顾读屏用户。注意 data-tip 的文字是 CSS 伪元素渲染的，读屏软件不会念它。两者分工：aria-label 只说动作（如「保存」），快捷键、结果这类补充留给气泡（如「保存 (Ctrl+S)」），不要求两者逐字一致。

键盘能弹，而且不拦截焦点

气泡在两种时机出现：鼠标 :hover，或键盘把焦点移到按钮上（daisyUI 用 :has(:focus-visible) 识别，点鼠标产生的焦点不触发）。移开 / 焦点走到别处，气泡立即消失。tooltip 不是弹层：焦点不被圈定、不用在气泡之间 Tab、Esc 与它无关——不要给它加 role="tooltip" 容器陷阱，也不要自己写键盘逻辑。只有当你确实希望读屏把气泡全文也念出来时，才把提示内容写成真实元素 <div class="tooltip-content" id="保存提示">，再在触发元素上挂 aria-describedby="保存提示"（伪元素 data-tip 无法被指向）——这时才要求气泡文字与 aria-label 保持一致。

按边缘选方向

默认上方；按钮贴着页面顶部就用 tooltip-bottom，贴着左右边缘就用 tooltip-left / tooltip-right。静态展示时加 tooltip-open 强制显示，并在舞台四周留足内边距，避免气泡顶出容器。

颜色语义化

默认中性灰最通用；tooltip-primary / tooltip-error 只在含义明确时使用，别为了给提示上色而滥用颜色。
