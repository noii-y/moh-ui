日期范围 Date Range

订单、报表、数据列表顶部的筛选条：两个原生日期框用 join 拼成一条，中间「至」分隔，再配今天 / 近 7 天 / 近 30 天 / 本月四个快捷预设。下面先给一个可以直接拿走的成品，再看各种简化形态。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会结合你的项目直接生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 日期框用原生 <input type="date">（自带日历面板，零依赖）；预设按钮的选中态用 aria-pressed 表达，点预设自动填日期只需要一小段原生 JS（成品已带上）。

使用指南

为什么用原生 date input

<input type="date"> 自带日历面板、键盘输入和移动端原生滚轮，零依赖零 JS 就能用，日期格式自动跟随系统语言。不要为了统一外观自己手写日历，那是一大坨 JS。

拼接与分隔

两个日期框都加 join-item，首尾圆角由 join 自动处理；中间的「至」用 join-item flex items-center px-3 bg-base-200，渲染成一条中性分隔条，并加 aria-hidden="true"（读屏不需要念这个字）。

快捷预设怎么表达选中

预设按钮用柔和态（btn btn-soft btn-sm），选中项加 aria-pressed="true"，同组同时只有一个为 true。外层包 role="group" aria-label="快捷预设"。视觉上选中态跟随主题色，不要写死颜色。

填充逻辑：仅一小段原生 JS

成品里的 JS 只做三件事：点哪个预设就把它的 aria-pressed 设为 true、其余设为 false；按预设算出起止日期（今天 / 近 7 天 = 今天往前 6 天 / 近 30 天 = 往前 29 天 / 本月 = 当月 1 号）；写回两个 input。日期格式化用本地时区（不要用 toISOString()，UTC 会让日期偏一天）。真实项目里，填完日期再发查询请求即可，这段 JS 可以原样搬。

查询与重置

「查询」是主操作用 btn-primary，「重置」是弱化动作用默认按钮。重置的真实动作是把两个 input 清空（或恢复默认值）并取消预设选中，需要时在上面那段 JS 里再加一个按钮分支。

窄屏

整条筛选条用 flex flex-wrap items-center gap-2 自然折行，不写任何响应式类；不要用 ml-auto 把按钮推到右边。390px 下日期条一行、预设和按钮依次换到下面，任何元素不被裁切。
