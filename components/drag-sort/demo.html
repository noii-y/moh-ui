拖拽排序 Drag & Drop Sort

后台菜单、配置列表的顺序调整：鼠标拖拽即换序，把手聚焦后可用 ↑/↓ 键移动，目标位高亮、屏幕阅读器播报结果。样式全部走 daisyUI 类、零依赖；换序本身需要页面内嵌一小段原生 JavaScript（无第三方拖拽库）。

三步用到你项目里

  1. 在页面里引入两行样式：daisyui.css 和 utilities-patch.css（本项目都已打包，零依赖、无需构建）。
  2. 首选点「复制 AI 提示词」，整段发给你的 AI，它会连同那一小段原生换序 JS 一起生成；想自己粘贴代码，再用「复制成品 HTML」，保存成 .html 双击即可预览。
  3. 增删菜单项只改 <li>：每项的 data-label 与可见名称保持一致；换序后把新顺序提交给你的后端接口保存即可。

后台「菜单管理」的排序列表

管理员按使用频率调整左侧菜单的显示顺序：按住一行上下拖动即可换序，被拖动项半透明、目标行主色描边高亮；键盘用户 Tab 到左侧把手后按 ↑/↓ 也能移动，屏幕阅读器会播报「已将 X 移动到第 N 位」。

  • 角色与权限
  • 审计日志
  • 系统设置

使用指南

纯 CSS 做不到，必须配一小段原生 JS

拖拽换序依赖浏览器的 HTML5 Drag & Drop API，任何纯 CSS 组件库都做不到。本组件的样式全部用 daisyUI 类（零依赖、随主题变色），换序行为是页面内嵌的一小段原生 JavaScript：监听 dragstart / dragover / drop / dragend 并用 insertBefore 移动节点，不到 50 行、不引入任何第三方拖拽库。把成品保存为 .html 双击即可直接拖动。

鼠标与键盘双通道

鼠标按住整行拖动即可换序；键盘用户 Tab 到左侧把手按钮，聚焦后按 ↑ / ↓ 上下移动这一项，移动后焦点仍留在把手上，可连续移动。dragover 里按鼠标在目标行上半段还是下半段决定插入位置，所以拖动过程中列表实时跟随。

可访问性

把手是 <button> 而不是图标字符，带 aria-label="拖拽排序：行名"；拖拽与键盘移动后，隐藏的 aria-live="polite" 区域播报「已将 X 移动到第 N 位」，屏幕阅读器用户同样知道结果。锁定行用 aria-disabled="true"，脚本里同步跳过它，既不能拖也不能键盘移动。

排序结果要自己保存

这套交互只改前端 DOM。用户点「保存」时，按 ul 当前的子节点顺序，把每行的 data-label（或你的业务 id）组成数组提交给后端，由后端持久化；刷新页面后再按后端返回的顺序渲染。

视觉细节

拖拽中被拖行加 opacity-50，当前目标行加 border-primary 高亮，松手自动清除；把手图标用内联单色 SVG（六点 grip），不要用 ≡ 这类字符——字符在不同字体下错位，也没有正确的语义。
