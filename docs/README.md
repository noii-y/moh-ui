# docs/

项目文档。

## 现行规范

- `moh-json-spec.md` —— `moh.json` 资源元数据规范（字段、必填项、溯源写法）
- `license-policy.md` —— 素材引入流程与许可证对照（含 tokyo-night 的 Apache-2.0 合规要求）
- `git-notes.md` —— Windows 下推送到 GitHub 的环境备忘（全局加速镜像导致 push 失败的处理）

## 规划与历史归档

- `主题扩充选题表.md` —— 主题扩量时的候选清单与分组记录
- `开发计划.md` —— 2026-10-16 立项规划快照，部分早期方案已被实际演进取代
- `theme-conversion.md` —— 旧 `--moh-*` 体系的主题转换规范，已被 daisyUI `[data-theme]` 取代
- `component-spec-c.md` —— 旧单文件组件的行为规格，组件已改为 daisyUI 三件套

了解项目现状以根目录 `README.md` 为准，协作规范以根目录 `AGENTS.md` 为准。
