# 灰墨规则边界包 · 主规则（v0）

> 用途：给 AI 编程工具用的"审美整容"指令。当用户说"用灰墨规则美化我的后台 / 管理系统 / SaaS 控制台"时，AI 按本文件逐项执行。
> 规则是**边界**不是风格：不限定用户用什么颜色、什么风格，只拦住"不专业"的默认行为——字体过大过小、表格溢出、间距混乱、对比度不足、动效花哨。
> 配套：`rules/scenarios/` 分场景规则（表格/表单/数据看板）+ `rules/selfcheck.md` 自检清单（AI 交付前逐项自查）。执行完必须跑自检。

## 0. 执行方式

1. 先通读本项目规则全部文件（主规则 + 相关场景规则 + 自检清单）；
2. 逐条对照目标项目，发现违反处**直接修改**，不留待办；
3. 全部改完，按 `selfcheck.md` 逐项自查；任一未过 → 修复 → 重查，最多 3 轮；
4. 自检全过才算交付。

## 1. 字号（硬边界）

- 正文默认 **14px**，允许范围 **13–16px**；
- 页面标题最大 **24px**，区块标题 20px，卡片标题 16px；
- **一页字号阶 ≤ 5 级**（同一屏出现 5 种以上字号 = 违规）；
- 表格 / 表单正文 13px，辅助信息（时间戳、说明文字）12px；
- 数字与金额使用等宽数字（`font-variant-numeric: tabular-nums` 或等宽字体），保证列对齐；
- 全站字体权重 ≤ 3 个（如 400 / 500 / 600），禁止 700+ 大面积使用。

## 2. 表格（硬边界）

- **宽度不超出容器**：优先自适应；列多时允许水平滚动（`overflow-x: auto`），禁止撑破布局；
- **单元格内容不溢出**：超长文本截断省略（`text-overflow: ellipsis` + 固定最大宽），或允许换行，二选一；
- 数字列**右对齐**，文本列左对齐，表头与列对齐方式一致；
- 行高一致（推荐 40px 常规行），斑马纹与分隔线**二选一**，不叠加；
- 表头有层级（加粗或颜色区分），可排序列给出排序指示；
- 空数据必须有**空态提示**（"暂无数据"+ 引导），禁止留白页。

详见 `rules/scenarios/table.md`。

## 3. 间距（硬边界）

- 使用 **8px 网格**（所有间距是 4 的倍数：4/8/12/16/24/32）；
- 卡片内边距 16px，卡片间距 16px，区块间距 24px；
- 控件（按钮/输入/下拉）高度统一 **32px**，同组控件间距 8px；
- 文字与相邻元素间距 ≥ 8px，禁止贴边、叠字。

## 4. 对齐（硬边界）

- 文本左对齐、数字右对齐、布尔/状态居中，全库一致；
- 表单标签与输入框**垂直对齐**（同一行标签与控件基线一致）；
- 页面级操作按钮组右对齐，卡片内操作按钮组卡片底部右对齐；
- 同一区块内的元素有明确的左对齐基准线，禁止随意缩进。

## 5. 颜色与对比度（硬边界）

- 正文与背景对比度 **≥ 4.5:1**（WCAG AA）；大号文字（≥24px）≥ 3:1；
- 次级文字（muted）对比度 ≥ 3:1 且不模糊；
- **禁止大面积高饱和撞色**；主色全库唯一（一个主色 + 一个危险色 + 语义状态色）；
- 所有颜色**走 CSS 变量**（`--moh-*`），禁止散落硬编码色值；
- 状态色语义化：成功=绿、警告=黄/橙、危险=红，同类状态全库一致；
- 深色主题下文字用近白（非纯白 #fff 刺眼，推荐 #f7f8f8），浅色主题下文字用近黑（推荐 #1a202c）。

## 6. 布局与密度（硬边界）

- 内容不贴边：页面内容区有统一边距（≥16px，推荐 24px）；
- 结构统一：顶栏 / 侧边栏 / 内容区三层清晰，导航激活态明确；
- **一屏视觉区块 ≤ 10 个**，超出则折叠或分页；
- 信息密度合理：不堆砌（每屏重点 ≤ 3 个），也不过度留白（空白 ≥ 视口 60% 视为过疏）。

## 7. 交互与动效（硬边界）

- 所有可点击元素有 **hover 态与 focus 态**（focus 用 2px 主色描边 + offset）；
- 禁用态明确（透明度 0.5 + `cursor: not-allowed`）；
- 动效 ≤ 200ms，仅 hover / 过渡 / 展开用；**禁止闪烁、缩放、弹跳类动画**；
- 加载与空态有反馈（骨架屏或 loading 文字），禁止无反馈卡顿。

## 8. 禁则（一票否决）

以下任何一项出现即判不合格，必须清除：

1. 大面积渐变背景（径向/线性渐变做按钮背景除外的小面积点缀）；
2. 阴影堆叠（同一元素 > 2 层阴影）；
3. 花哨 CTA（渐变大按钮 + 夸张文案 + 发光效果）；
4. emoji 当图标（一律用 SVG 图标，单色、随文字色）；
5. 装饰性动效（入场飞入、循环呼吸、滚动视差）；
6. 字体权重混乱（> 3 个 weight）；
7. 硬编码颜色 / 字号 / 间距残留（未走变量的）；
8. 一屏 > 10 个视觉区块；
9. 表格溢出容器；
10. 内容贴边无呼吸感。

## 9. 完成后

- 按 `rules/selfcheck.md` 自查全过；
- 主题若可应用（有 tokens.css），优先配合 `themes/` 主题包使用；规则与主题冲突时**以规则为准**。
