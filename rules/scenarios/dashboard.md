# 场景规则 · 数据看板（v0）

> 配合主规则 `mo-rules-zh.md` 使用。AI 处理数据看板 / 仪表盘页面时，在满足主规则基础上执行本细则。

## 1. 层级

- 看板 = 顶栏（标题 + 时间范围/筛选）+ KPI 区 + 图表区 + 明细表区，自上而下；
- 每屏重点 ≤ 3 个，次要数据折叠或放后；
- 区块用卡片承载，卡片间距 16px，同排卡片高度尽量一致。

## 2. KPI 卡

- 每张 KPI 卡：指标名（13px muted）+ 数值（24px 粗体，等宽数字）+ 变化（12px，正绿负红）；
- 数值对齐：同排 KPI 卡的数值右对齐或左对齐统一；
- 变化率语义：上升用绿色（或主题成功色），下降用红色（危险色），全库一致；
- 有单位/口径说明放数值下方 12px muted，禁止裸数字无解释。

## 3. 图表

- 图表统一用主题变量色（主色 + 语义色），禁止自带高饱和默认配色；
- 坐标轴标签 12px muted；图例放图表上方或右侧，12px；
- 柱状图/条形图：刻度从 0 开始，禁止截断误导；
- 折线图：趋势线 2px，数据点克制（≤ 每 10 个点标一个）；
- 饼图/环形图：切片 ≤ 6 块，其余合并"其他"；
- 图表无数据时给空态，禁止空白框；
- 图表区域宽度不超出卡片，高度统一（KPI 区图表 ≤ 300px）。

## 4. 时间范围与筛选

- 时间范围控件（今天/7天/30天/自定义）放顶栏右侧，默认 7 天；
- 筛选条件变化立即刷新，刷新中给 loading，禁止闪白；
- 数据更新时间标注（"更新于 10:32"）12px muted，放看板角落。

## 5. 密度

- 一屏图表/卡片区块 ≤ 10 个；
- 深色看板优先（数据看板类项目默认 mo-dark 基底），但对比度仍 ≥ 4.5:1；
- 数字列全部等宽数字对齐，禁止小数点后位数不一致。
