# 场景规则 · 表单（v0）

> 配合主规则 `mo-rules-zh.md` 使用。AI 处理含表单的页面时，在满足主规则基础上执行本细则。

## 1. 布局

- 单列表单：字段从上到下排列，标签在上（或左），全表单一致；
- 双列/多列表单：卡片内网格布局，列间距 16px，行间距 16px；
- 字段宽度：输入框统一满宽（`width: 100%`，由列容器约束），禁止参差不齐；
- 短字段（数字/日期）可以固定窄宽，但同类字段宽度一致。

## 2. 标签

- 每个字段有标签，标签与控件间距 8px；
- 必填项统一标记（红色 `*`，推荐 `required` 语义 + 视觉标记）；
- 说明文字：字段下方 12px muted 色，与输入框间距 4px；
- 长表单分组：用分组标题（16px）分隔，组间距 24px。

## 3. 控件

- 输入框 / 下拉 / 日期统一高度 32px，圆角与主题一致（4–8px）；
- 焦点态：主色描边 + 3px 主色浅底光晕；
- 错误态：红描边 + 错误提示文字（字段下方），**同时**要有 `aria-invalid` 语义；
- 禁用态：透明度 0.5，明确不可点。

## 4. 校验

- 必填、格式（邮箱/手机/URL）、长度校验即时反馈（失焦即查）；
- 错误提示写人话：如"请输入 11 位手机号"，禁止只报英文 error code；
- 提交按钮在表单底部，主按钮 + 次要按钮（取消）成组，间距 8px，右对齐或左对齐统一。

## 5. 提交与反馈

- 提交中：按钮 loading 态（转圈 + 禁用），禁止无反馈双击；
- 成功后：明确成功提示（toast 或页面反馈），禁止静默；
- 失败后：保留用户已填内容，只标错字段，禁止清空重填。
