# 场景规则 · 表格（v0）

> 配合主规则 `mo-rules-zh.md` 第 2 节使用。AI 处理含表格的页面时，在满足主规则基础上执行本细则。

## 1. 列

- 列数过多（>6 列）时：保留核心列，次要列折叠或支持隐藏；
- 列宽分配：文本列自适应，数字列固定（保证右对齐），操作列固定最窄（按钮/链接）；
- 超长文本：固定最大宽（如 200px）+ `text-overflow: ellipsis`，悬停 title 显示全文；或允许换行，二选一。

## 2. 对齐

- 文本左对齐；数字 / 金额 / 百分比右对齐（等宽数字）；状态 / 开关 / 图标居中；
- 表头对齐方式与对应列一致（表头数字列也右对齐）。

## 3. 分隔

- 分隔线或斑马纹二选一，不叠加；
- 用分隔线：行间 1px `border-bottom`，最后一行去除；
- 用斑马纹：奇数/偶数行交替 `--moh-surface-2`，色差不能太跳（同色系 ±5% 明度内）。

## 4. 行

- 行高一致（常规 40px，紧凑 32px，全表统一）；
- hover 行有反馈（底色变化，禁用条纹叠加的跳色）；
- 选中行有明确态（主色浅底 + 主色描边），单选/多选有全选与反选。

## 5. 排序与筛选

- 可排序列表头带排序指示（▲/▼ 或 SVG），点击切换升/降/无；
- 排序后数据立即更新，不闪烁；
- 筛选器放表格上方，与表格间距 12px。

## 6. 分页与状态

- 分页器：上一页/下一页 + 页码 + 总数（"共 N 条"），当前页明确高亮；
- 加载中：骨架屏或半透明遮罩 + loading 提示；
- 空态：图标 + "暂无数据" + 操作引导（如"新建"按钮），禁止纯空白页；
- 错误态：重试按钮 + 错误说明，禁止空白。

## 7. 响应式

- 窄屏（<760px）：允许水平滚动，或卡片化（每行变一张卡），禁止列挤压变形；
- 优先水平滚动（改动小、稳）。
