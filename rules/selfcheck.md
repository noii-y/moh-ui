# 灰墨自检清单（v0）

> 规则边界包的**验收层**。AI 按主规则 + 场景规则修改完成后，逐项勾选；任一未过 → 修复 → 重查，最多 3 轮，全过才交付。
> 也可独立用于"我的项目套了灰墨主题/规则后自查"。

## A. 基础

- [ ] 1. 正文 13–16px，页面标题 ≤ 24px，一页字号阶 ≤ 5 级
- [ ] 2. 全站字体权重 ≤ 3 个
- [ ] 3. 数字/金额使用等宽数字，列内对齐

## B. 表格（有表格才查）

- [ ] 4. 表格宽度不超出容器（溢出有滚动或自适应）
- [ ] 5. 单元格无溢出（截断省略或换行）
- [ ] 6. 数字列右对齐、文本左对齐，表头同列一致
- [ ] 7. 分隔线或斑马纹二选一，未叠加
- [ ] 8. 空数据有空态提示

## C. 间距与对齐

- [ ] 9. 间距均为 4 的倍数（8px 网格）
- [ ] 10. 控件高度统一 32px，同组间距 8px
- [ ] 11. 表单标签与控件垂直对齐，按钮组对齐统一
- [ ] 12. 内容不贴边，页面有统一边距

## D. 颜色

- [ ] 13. 正文对比度 ≥ 4.5:1
- [ ] 14. 全部颜色走 CSS 变量，无硬编码色值残留
- [ ] 15. 主色唯一，状态色语义化（成功绿/警告橙/危险红）且全库一致
- [ ] 16. 无大面积高饱和撞色

## E. 交互与动效

- [ ] 17. 可点击元素有 hover 与 focus 态
- [ ] 18. 禁用态明确（透明度 0.5 + not-allowed）
- [ ] 19. 动效 ≤ 200ms，无闪烁/缩放/弹跳动画

## F. 禁则（一票否决）

- [ ] 20. 无大面积渐变背景
- [ ] 21. 无阴影堆叠（同元素 ≤ 2 层）
- [ ] 22. 无花哨 CTA
- [ ] 23. 无 emoji 当图标
- [ ] 24. 一屏视觉区块 ≤ 10 个

## G. 技术正确性

- [ ] 25. 无未定义 CSS 变量、无 404、控制台无报错
- [ ] 26. 桌面（1280px）与手机（375px）双视口检查通过，无布局破损
