灰墨 · mo-dark（墨夜 · 深色）主题包

MoH_UI · AI 主题包 目标：给 AI 搭出来的后台 / 管理系统做审美急救。

这是什么

一套现成的深色后台主题，由三个文件组成：

  • tokens.css — 设计变量（色彩 / 字体 / 字号 / 间距 / 圆角 / 阴影），全部以 --moh-* 命名
  • base.css — 基础组件样式（按钮 / 输入 / 表格 / 卡片）
  • preview.html — 预览基准页（应用后以此为准对照检查）

使用指令（给 AI 编程工具）

当你被要求"应用灰墨 mo-dark 主题"，请执行：

  1. 获取本主题的 tokens.css 与 base.css 两个文件的内容
  2. 在目标项目引入：<link rel="stylesheet" href="tokens.css" /> 与 <link rel="stylesheet" href="base.css" />（路径按项目结构调整）
  3. 把项目中与 --moh-* 冲突的旧变量、内联颜色、硬编码样式清理或替换为变量引用
  4. 组件类名统一使用 moh-btn / moh-input / moh-table / moh-card / moh-tag 等 moh- 前缀

关键设计变量（tokens.css 摘要）

--moh-canvas: #0f0f0f   /* 页面底 */
--moh-surface: #1b1b1f  /* 卡片 / 面板 */
--moh-surface-2: #232328
--moh-border: #2a2a30
--moh-ink: #f7f8f8      /* 主文字 */
--moh-muted: #9ca3af    /* 次级文字 */
--moh-primary: #5e6ad2  /* 主色 */
--moh-primary-hover: #7b84e0
--moh-primary-muted: #262a4d
--moh-radius-sm: 4px; --moh-radius-md: 6px; --moh-radius-lg: 8px
--moh-text-base: 14px; 字号阶 12/13/14/16/20/24
--moh-space-2: 8px; 间距 4 的倍数（8px 网格）

应用后自检清单（AI 交付前必须自查）

  1. 文件写入：tokens.css 与 base.css 已创建且被引用
  2. 变量生效：页面背景变深色（#0f0f0f 系），主文字为浅色（#f7f8f8 系）
  3. 组件渲染：按钮 / 输入框 / 表格的圆角、边框、间距与 preview.html 一致
  4. 对比度：正文与背景对比度 ≥ 4.5:1（WCAG AA），次级文字不模糊
  5. 无报错：无未定义变量、无 404、控制台无错误

任一未通过 → 修复后重查，最多 3 轮，达标后再交付。
