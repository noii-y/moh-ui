# 驰途调度 · 浅色（mo-fleet）

物流配送调度台高对比功能色主题。白底高对比、状态语义一眼可读（待取/配送中/签收/异常），面向城配调度场景；挂 `data-theme="mo-fleet"` 即整站换肤。

## 文件

- `tokens.css` — daisyUI 5 主题变量（覆盖 `--color-*`、圆角、尺寸、边框），自写原创、无外部 LICENSE
- `demo.html` — 完整页面案例：虚构物流调度台整页（品牌顶栏 + 左侧调度导航 + 时效 KPI 行 + 网格实时地图 SVG 态势 + 在岗骑手列表 + 待处理运单列表 + 真实操作按钮 + 页脚），全部用 daisyUI 组件拼装、零依赖、零 JS

## 使用（在已有 daisyUI 的项目里换肤）

```html
<html data-theme="mo-fleet">
  <head>
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/daisyui@5" />
    <link rel="stylesheet" href="tokens.css" />
  </head>
</html>
```

只引入 daisyUI 与本主题两个 CSS 即可整站换肤；`demo.html` 整页可直接复制（结构 + 类名）当物流调度后台模板。

## 本主题的硬边界

- **状态语义四色全加深**：信息蓝 `#173FA8`（待取件，白字 9.1:1）、调度深蓝 `#1C4F9E`（配送中/主操作，白字 7.9:1）、签收绿 `#175A22`（白字 8.3:1）、异常红 `#A01B1B`（白字 7.9:1）；警告棕 `#6B4400`（白字 8.6:1）只做即将超时提醒。状态徽章必须配中文文字，不靠颜色单独传达。
- **正文对比度充足**：正文 `#141A22` 白底 17.5:1、次级 `#3A4450` 白底 9.9:1；不要用 opacity 压文字。
- **主色克制**：`#1C4F9E` 只留给派单主按钮与当前导航，禁止大面积渐变铺底；加急件才用琥珀棕 `#8A5A00`。
- **KPI 是克制小卡**：标签 13px 中性色 + 大数字 28px + 12px 副说明，不是营销大卡。
- **地图必须成形**：网格 + 主干道 + 语义色点位圆点 + 虚线在途路线 + 中文图例，禁止空灰块占位。
- **按钮写真实动作**：派发选中运单/改派订单/联系骑手，不写颜色名与营销词。
- 页内企业名「驰途调度」、骑手姓名、运单号与位置数据均为虚构示例。
