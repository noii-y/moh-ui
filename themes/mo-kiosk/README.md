# 暖茶点单 · 暖色（mo-kiosk）

餐饮门店堂食自助点单的触控大屏主题。暖奶油底、烤棕主色、超大触控按钮、左右三栏；这是店里固定横屏大屏，不是手机移动端点单。挂 `data-theme="mo-kiosk"` 即整站换肤。

## 文件

- `tokens.css` — daisyUI 5 主题变量（覆盖 `--color-*`、圆角、尺寸、边框），自写原创、无外部 LICENSE
- `demo.html` — 完整页面案例：虚构奶茶店「暖茶茶饮 WARM CHA」自助点单整页（顶行品牌与取餐号 + 左五分类大按钮 + 中间八款超大方形菜品按钮 + 右购物车清单与下单），全部用 daisyUI 组件拼装、零依赖、零 JS

## 使用（在已有 daisyUI 的项目里换肤）

```html
<html data-theme="mo-kiosk">
  <head>
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/daisyui@5" />
    <link rel="stylesheet" href="tokens.css" />
  </head>
</html>
```

只引入 daisyUI 与本主题两个 CSS 即可整站换肤；`demo.html` 整页可直接复制（结构 + 类名）当堂食点单屏模板。

## 设计要点（本主题的硬边界）

- **横屏大屏三栏**：主场景按 1280 宽设计（分类栏 / 菜品网格 / 购物车），按钮超大；390px 自检时三栏自然退单列——分类横滑条、菜品两列、购物车在下，不横向溢出。
- **对比度已实测**：正文 `#332517` 纸面 13.5:1、说明文字 `--color-neutral` #6B5844（奶油底 6.18:1 / 购物车底 5.53:1）、主按钮烤棕 `#8A4B1F` 配奶油字 6.31:1、焦糖 `#96500A` 奶油字 5.68:1；**不要用 opacity 压文字**。
- **主色只此一个**：`#8A4B1F` 只留给「下单」与当前分类；抹茶绿 `#4C6B32` 全页只给「堂食」选中 pill；焦糖只做价格与取餐号，禁止焦糖大面积铺底。
- **触控尺寸**：菜品按钮 ≥178px 高、分类按钮 ≥72px、数量加减按钮 40×40px、下单按钮 64px 高，文字 ≥17px。
- **图标要区分杯型**：招牌奶茶（直杯+吸管+珍珠）、奶绿（杯+叶）、珍珠奶茶（满杯珍珠）、杨枝甘露（分层）、鲜橙茶（杯旁橙片）、纯茶（带碟茶杯+蒸汽）、拿铁（带把玻璃杯）、鸡米花（开口盒+圆粒），全部 currentColor 单色线稿。
- **信息少而清**：无注册登录、无营销横幅；按钮写真实动作；购物车显示名称、数量加减、行价、合计与下单。
