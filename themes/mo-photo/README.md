# 见山影集 · 浅色（mo-photo）

摄影师个人作品集的安静画廊主题。米白暖纸、衬线大标题、大留白、装裱作品框；与官方 `black`（纯黑影棚式）一浅一深。挂 `data-theme="mo-photo"` 即整站换肤。

## 文件

- `tokens.css` — daisyUI 5 主题变量（覆盖 `--color-*`、圆角、尺寸、边框），自写原创、无外部 LICENSE
- `demo.html` — 完整页面案例：虚构摄影师「见山摄影 · 林见山」整页（衬线品牌顶栏 + 大留白 Hero + 四幅装裱作品框 + 三个系列卡 + 关于图文与日志 + 约拍 CTA + 虚构声明页脚），全部用 daisyUI 组件拼装、零依赖、零 JS

## 使用（在已有 daisyUI 的项目里换肤）

```html
<html data-theme="mo-photo">
  <head>
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/daisyui@5" />
    <link rel="stylesheet" href="tokens.css" />
  </head>
</html>
```

只引入 daisyUI 与本主题两个 CSS 即可整站换肤；`demo.html` 整页可直接复制（结构 + 类名）当摄影作品集模板。

## 设计要点（本主题的硬边界）

- **浅色画廊，绝不改黑底**：本套与官方 black 刻意拉开一浅一深；背景是米白暖纸 `#F6F1E7`，严禁换成深色影棚风。
- **对比度已实测**：正文 `#2A251E` 纸面 13.5:1、次级 `#4F5B66` 纸面 6.18:1、主按钮胡桃木棕 `#5F4229` 配奶油字 8.48:1、古铜 `#7C4F14` 奶油字 6.53:1；**不要用 opacity 压文字**，需要淡一档就换色。
- **主色只此一个**：`#5F4229` 只留给主按钮、当前导航与链接；古铜点睛只能小面积，禁止大面积铺底。
- **衬线 + 大留白**：标题用宋体衬线、字距放宽；Hero 上下留白 ≥80px、作品框间距 ≥40px、页宽 ≤1040px。
- **作品框是装裱结构**：细线外框 + 暖纸衬底 + 框内有构图的单色线稿（山水/人像/街景/建筑），不空块、不用真照片。
- **390px**：顶栏与导航自然折行、作品框与系列卡单列、图文上下堆叠；无 `position:fixed`、无横向滚动。
